8.2.1 Creando tuplas

FPD - Free Text

En Python, las tuplas son estructuras de datos muy similares a las listas, pero con una diferencia importante: son inmutables, es decir, sus elementos no pueden modificarse una vez creadas.

Elaboración propia. Clic para ampliar.

Para definir una tupla, se utilizan paréntesis () en lugar de corchetes [].

# Ejemplos de creación de tuplas
empty_tuple = ()
coordenadas = (41.3879, 2.16992)
colores_primarios = ("Rojo", "Verde", "Azul")

Las tuplas son especialmente útiles cuando se desea agrupar datos que no deben cambiar durante la ejecución del programa.

Tuplas de un solo elemento

Un detalle importante al crear tuplas es cuando solo se quiere incluir un único elemento. Si se usa únicamente el paréntesis, Python interpreta el valor como una cadena, número o lo que corresponda, pero no como una tupla.

una_tupla = ("Málaga")
print(type(una_tupla))  # Resultado: <class 'str'>

Para crear correctamente una tupla de un solo elemento, es necesario añadir una coma después del valor:

una_tupla = ("Málaga",)
print(type(una_tupla))  # Resultado: <class 'tuple'>

Recuerde: la coma final es lo que define a la tupla de un solo elemento, no los paréntesis.

Tuplas sin paréntesis

En algunos casos, las tuplas pueden crearse sin necesidad de usar paréntesis. Python permite este formato por comodidad, especialmente en asignaciones múltiples.

# Ejemplos de tuplas sin paréntesis
una_tupla = "Málaga",
ciudades = "Sevilla", "Granada", "Córdoba"
coordenadas = 40.4168, -3.7038

print(type(ciudades))  # Resultado: <class 'tuple'>

Aunque este estilo es totalmente válido, el uso de paréntesis es preferible por claridad, especialmente en código de aprendizaje o cuando la tupla forma parte de una estructura más compleja.

A Step Ahead

Comparativa con otros lenguajes

Aunque las tuplas son una estructura muy utilizada en Python, no todos los lenguajes de programación las implementan de forma nativa o con la misma sencillez.

Lenguaje Soporte de tuplas Ejemplo
Python Soporte nativo. Las tuplas pueden contener elementos de distintos tipos y se crean fácilmente con paréntesis. persona = ("Ana", 28, "Valencia")
Java No tiene tuplas nativas, pero pueden simularse con clases personalizadas o usando la clase Pair o Record (desde Java 14). record Persona(String nombre, int edad, String ciudad) {}
C++ Desde C++11 dispone de la clase std::tuple en la biblioteca estándar, que permite agrupar varios valores. auto persona = std::make_tuple("Ana", 28, "Valencia");

En resumen, Python destaca por la simplicidad y flexibilidad en el uso de tuplas, mientras que en otros lenguajes suelen requerir estructuras más formales o bibliotecas específicas.

Now it's your turn

En Python, una tupla es una estructura de datos que, al contrario de una lista , es inmutable . Se pueden crear tuplas usando paréntesis , aunque también se pueden definir sin ellos, separando los elementos por comas . Para crear una tupla de un solo elemento es obligatorio añadir una coma al final.
