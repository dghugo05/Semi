8.3.6 Objetos "hashables"

FPD - Free Text

En Python, las claves de un diccionario deben ser hashables. Un objeto se considera hashable si se le puede asignar un valor hash que permanezca constante durante toda su vida útil.

La función hash() permite obtener el valor hash de un objeto. Este valor entero se utiliza internamente para indexar la tabla hash del diccionario.

# Números enteros y flotantes
hash(42)
# 42

hash(3.1415)
# 87592698408193

# Cadenas de texto
hash('python')
# -5748392018482193421

# Tuplas inmutables
hash(('x', 'y', 'z'))
# 901827364918273645

Para que un objeto sea hashable, debe ser inmutable. La imagen siguiente ilustra este concepto.

Por ejemplo, las listas no son hashables y producirán un error si se intenta obtener su hash:

hash(['apple', 'banana', 'cherry'])
# TypeError: unhashable type: 'list'

Nota: Como consecuencia, las claves de los diccionarios sólo pueden ser objetos inmutables, como números, cadenas, tuplas o booleanos.

Nota: Cualquier intento de usar un objeto mutable como clave, como listas, diccionarios o conjuntos, provocará un TypeError.

Resumen: Las claves hashables garantizan que los diccionarios puedan acceder a sus valores de manera eficiente mediante la tabla hash interna.

A Step Ahead

Para saber más: Objetos hashables

Para profundizar en el concepto de objetos hashables y en las restricciones de las claves de los diccionarios, se recomienda consultar la documentación oficial de Python. La sección de diccionarios explica las restricciones sobre las claves y el comportamiento de los diccionarios: https://docs.python.org/3/library/stdtypes.html#mapping-types-dict.

La función hash() muestra cómo se calcula el hash de un objeto y su relación con la tabla hash interna: https://docs.python.org/3/library/functions.html#hash.

Para entender qué objetos pueden ser utilizados como claves, conviene revisar los tipos inmutables y mutables: https://docs.python.org/3/library/stdtypes.html#common-sequence-operations.

Por último, la documentación sobre el método mágico __hash__() explica cómo los objetos definen su valor hash: https://docs.python.org/3/reference/datamodel.html#object.__hash__.

Revisar estas secciones permite comprender por qué algunos objetos son hashables y otros no, y cómo esto afecta al uso de diccionarios en Python.
