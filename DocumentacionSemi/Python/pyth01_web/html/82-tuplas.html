8.2 Tuplas

FPD - Free Text

Las tuplas en Python son estructuras de datos que permiten almacenar múltiples elementos en una única variable, de forma similar a las listas, pero con una diferencia clave: las tuplas son inmutables. Esto significa que, una vez creadas, no pueden modificarse (no es posible añadir, eliminar o cambiar elementos).

Representación conceptual de una tupla.

Elaboración propia. Clic para ampliar.

Las tuplas se definen utilizando paréntesis () en lugar de corchetes [], y los elementos se separan por comas.

# Ejemplo de creación de tuplas
empty_tuple = ()                     # tupla vacía
person = ("Ana", 25, "Madrid")       # tupla con datos heterogéneos
numbers = (3, 7, 9, 12)              # tupla con números
mixed = (1, "hola", 3.5, True)       # mezcla de tipos

# Acceso a los elementos de una tupla (igual que en listas)
person[0]
# 'Ana'
person[-1]
# 'Madrid'

Al ser inmutables, las tuplas resultan muy útiles cuando se desea garantizar que los datos no cambien durante la ejecución del programa. Por ejemplo, se pueden usar para representar coordenadas, colores o registros que no deban alterarse.

Consejo: Si un conjunto de datos no debe modificarse, utiliza tuplas en lugar de listas. Esto mejora la seguridad de los datos y, en muchos casos, el rendimiento del programa.

Una tupla es una estructura de datos similar a una lista pero con una característica importante: las tuplas son inmutables, lo que significa que sus elementos no pueden modificarse una vez creadas.

Para definir una tupla, se utilizan paréntesis en lugar de corchetes, y los elementos se separan por comas.

Ejemplo: person = ("Ana", 25, "Madrid")

Para acceder a un elemento de la tupla, se puede usar su índice como en las listas. Por ejemplo, person[0] devolverá el valor Ana.
