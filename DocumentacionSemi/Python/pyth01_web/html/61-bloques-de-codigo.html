6.1 Bloques de código

FPD - Free Text

En Python, a diferencia de otros lenguajes que utilizan llaves { } para delimitar bloques de código, se ha optado por un enfoque más visual y legible. Los bloques se definen mediante espacios en blanco, preferiblemente de cuatro espacios. Este espacio se conoce como nivel de indentaciónEspacios o tabulaciones al inicio de una línea de código que delimitan bloques o estructuras de control; en Python, la indentación es obligatoria para definir la jerarquía del código. y es fundamental para que el intérprete comprenda la estructura del programa.

Esta decisión del creador del lenguaje, Guido van Rossum, busca simplificar la escritura y mejorar la legibilidad del código, eliminando caracteres que pueden considerarse innecesarios.

Consejo: Para quienes provienen de lenguajes que usan llaves, esta forma de definir bloques puede parecer extraña al principio, pero rápidamente se vuelve natural a medida que se adquiere experiencia escribiendo código en Python.

FPD - Free Text

Ejemplo de indentación en un bloque if:

edad = 20

if edad >= 18:
    print("Eres mayor de edad")
    print("Puedes acceder al contenido")
else:
    print("Eres menor de edad")
    print("No puedes acceder al contenido")

En este ejemplo se observa cómo los bloques de código se definen mediante indentación (espacios en blanco). Cada sentencia dentro del if y del else debe estar alineada al mismo nivel de sangría, de lo contrario Python lanzará un error de sintaxis. La indentación indica qué instrucciones pertenecen a cada bloque condicional.
