8.1.3 Operaciones con listas

FPD - Free Text

En Python, las listas son estructuras de datos versátiles que permiten almacenar múltiples elementos. Sobre ellas se pueden realizar una gran cantidad de operaciones, que facilitan el acceso, modificación, combinación y análisis de los datos.

Obtener un elemento

Al igual que en las cadenas de texto, se puede acceder a un elemento de una lista mediante su índice:

fruits = ['Manzana', 'Banana', 'Cereza']
fruits[0]
# 'Manzana'
fruits[1]
# 'Banana'
fruits[-1]  # acceso con índice negativo
# 'Cereza'

Es importante que el índice esté dentro de los límites de la lista, de lo contrario se generará un IndexError:

fruits[3]
# IndexError: list index out of range
fruits[-4]
# IndexError: list index out of range

Trocear una lista

El troceado de listas funciona de manera análoga al de cadenas de texto:

fruits = ['Manzana', 'Banana', 'Cereza', 'Kiwi', 'Melón']
fruits[1:4]
# ['Banana', 'Cereza', 'Kiwi']
fruits[:3]
# ['Manzana', 'Banana', 'Cereza']
fruits[-1:-4:-1]
# ['Melón', 'Kiwi', 'Cereza']
fruits[::-1]
# ['Melón', 'Kiwi', 'Cereza', 'Banana', 'Manzana']

Nota: Estas operaciones no modifican la lista original, simplemente devuelven una nueva lista.

Invertir una lista

Existen varias formas de invertir una lista:

  • Sin modificar la original: mediante troceado con step negativo o la función reversed().
  • Modificando la original: mediante reverse().

Conservando la lista original mediante troceado con step negativo

numbers = [10, 20, 30, 40, 50]
numbers[::-1]
# [50, 40, 30, 20, 10]

Conservando la lista original mediante la función reversed()

numbers = [10, 20, 30, 40, 50]
list(reversed(numbers))
# [50, 40, 30, 20, 10]

Modificando la lista original mediante reverse()

numbers = [10, 20, 30, 40, 50]
numbers.reverse()
numbers
# [50, 40, 30, 20, 10]

Nota: La diferencia entre reversed() y reverse() es que reversed() devuelve un nuevo iterador (se puede convertir en lista sin modificar la original), mientras que reverse() modifica la lista in-situ.

Añadir elementos

Para añadir elementos al final se utiliza append(). Para insertar en cualquier posición, insert(). Por ejemplo:

numbers = [2, 4, 6]
numbers.append(8)
# [2, 4, 6, 8]

numbers.insert(1, 3)
# [2, 3, 4, 6, 8]

Consejo: para añadir al final es más legible usar append() que insert() con len(lista).

Repetir y combinar listas

Se pueden repetir elementos con el operador * y combinar listas con + o extend():

letters = ['A', 'B']
letters * 3
# ['A', 'B', 'A', 'B', 'A', 'B']

list1 = [1, 2]
list2 = [3, 4]
list1 + list2
# [1, 2, 3, 4]

list1.extend([5, 6])
# [1, 2, 5, 6]

Modificar elementos

Se puede modificar un elemento individual o un trozo de la lista:

fruits = ['Manzana', 'Banana', 'Cereza']
fruits[0] = 'Pera'
# ['Pera', 'Banana', 'Cereza']

Modificar con troceado

No sólo es posible modificar un elemento de cada vez, sino que también se pueden asignar valores a trozos de una lista:

fruits = ["Manzana", "Banana", "Cereza", "Dátil", "Higo"]
fruits[1:4]
# ['Banana', 'Cereza', 'Dátil']
fruits[1:4] = ["Kiwi", "Mango"]
fruits
# ['Manzana', 'Kiwi', 'Mango', 'Higo']

Nota: La lista que asignamos no necesariamente debe tener la misma longitud que el trozo que sustituimos. Python ajusta automáticamente la lista al tamaño del nuevo contenido.

Borrar elementos

Se pueden eliminar elementos por índice (del), por valor (remove()), por extracción (pop()) o por rango (troceado). También es posible vaciar toda la lista con clear() o reasignando [].

Por su índice: utilizando del()

productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
del(productos[2])
productos
# ['Leche', 'Pan', 'Mantequilla', 'Zumo']

Por su valor: utilizando remove()

productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
productos.remove("Mantequilla")
productos
# ['Leche', 'Pan', 'Queso', 'Zumo']

Advertencia: Si existen valores duplicados, remove() solo eliminará la primera ocurrencia.

Por su índice con extracción: utilizando pop()

productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
productos.pop()
# 'Zumo'
productos
# ['Leche', 'Pan', 'Queso', 'Mantequilla']
productos.pop(1)
# 'Pan'
productos
# ['Leche', 'Queso', 'Mantequilla']

Nota: Si no se indica un índice, pop() elimina por defecto el último elemento.

Por rango: mediante troceado de listas

productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
productos[1:4] = []
productos
# ['Leche', 'Zumo']

Borrado completo de la lista

Se puede eliminar toda una lista de dos maneras:

    1. Utilizando clear() (borrado in-situ):
productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
productos.clear()
productos
# []
    1. Reinicializando la lista con [] (creando una nueva zona de memoria):
productos = ["Leche", "Pan", "Queso", "Mantequilla", "Zumo"]
productos = []
productos
# []

Nota: La diferencia entre ambos métodos está relacionada con la gestión de memoria y el rendimiento interno.

Otras operaciones útiles

Comprobar pertenencia, contar ocurrencias, convertir a cadena, ordenar, conocer longitud e iterar:

items = ['Pan', 'Leche', 'Huevos']
'Leche' in items
# True

items.count('Pan')
# 1

', '.join(items)
# 'Pan, Leche, Huevos'

sorted(items)
# ['Huevos', 'Leche', 'Pan']

len(items)
# 3

for item in items:
    print(item)
# Pan
# Leche
# Huevos

También se puede iterar con índices mediante enumerate() o combinar listas en paralelo con zip().

You Should Know

En Python, hay que tener cuidado con los índices al trabajar con listas, ya que algunas operaciones lanzan errores si se indica un índice fuera de rango, mientras que otras no.

Acceso a elementos individuales

Si se intenta acceder a un elemento mediante su índice y el índice está fuera del rango de la lista, Python lanza un IndexError. Esto aplica tanto para índices positivos como negativos.

productos = ["Leche", "Pan", "Queso"]

# Índice válido
print(productos[1])  # 'Pan'

# Índice fuera de rango (positivo)
print(productos[5])
# IndexError: list index out of range

# Índice fuera de rango (negativo)
print(productos[-4])
# IndexError: list index out of range

Modificación de elementos individuales

Intentar asignar un valor a un índice inexistente también genera IndexError.

productos[3] = "Mantequilla"
# IndexError: list assignment index out of range

Troceado (slicing)

Al utilizar troceado de listas (lista[start:end]), Python no lanza error aunque los índices estén fuera de rango. Ajusta automáticamente los límites al inicio o al final de la lista y devuelve una lista nueva.

productos = ["Leche", "Pan", "Queso"]

print(productos[1:10])  # ['Pan', 'Queso']
print(productos[-10:2]) # ['Leche', 'Pan']
print(productos[10:20]) # []

También aplica al reemplazar trozos de la lista:

productos[1:5] = ["Mantequilla", "Zumo"]
print(productos)  # ['Leche', 'Mantequilla', 'Zumo']

Funciones insert() y pop()

insert(index, valor): si el índice está fuera de rango, Python inserta el valor al principio o al final según corresponda, sin lanzar error.

productos = ["Leche", "Pan"]
productos.insert(10, "Queso")  # índice demasiado grande
print(productos)  # ['Leche', 'Pan', 'Queso']

productos.insert(-10, "Zumo") # índice demasiado pequeño
print(productos)  # ['Zumo', 'Leche', 'Pan', 'Queso']

pop(index): si no se indica índice, elimina el último elemento. Si el índice indicado está fuera de rango, lanza IndexError.

productos.pop(5)
# IndexError: pop index out of range

Resumen de comportamiento

La siguiente tabla resume cómo gestiona Python los índices fuera de rango:

Operación Índice fuera de rango Resultado
Acceso (lista[i]) Sí IndexError
Modificación (lista[i] = x) Sí IndexError
Troceado (lista[start:end]) No Ajusta al rango válido
Reemplazo por troceado No Ajusta al rango válido
insert(index, valor) No Inserta al inicio o final
pop(index) Sí IndexError

Resumen de operaciones

Operación Descripción
append() Añade un elemento al final de la lista.
insert() Inserta un elemento en la posición indicada.
extend() Añade todos los elementos de otra lista al final.

pop() Elimina y devuelve el elemento en la posición indicada (por defecto el último).
clear() Elimina todos los elementos de la lista.
index() Devuelve el índice de la primera ocurrencia de un elemento.
count() Cuenta cuántas veces aparece un valor en la lista.

sorted() Devuelve una lista ordenada sin modificar la original.
reverse() Invierte la lista in-situ.
enumerate() Itera sobre la lista proporcionando índice y valor.
zip() Permite iterar sobre varias listas en paralelo.
