5.2 Operaciones principales

FPD - Free Text

Las cadenas de texto en Python permiten realizar numerosas operaciones que facilitan su manipulación. A continuación, se presentan las más habituales con su definición y un ejemplo sencillo de uso. En la siguiente figura se puede ver el indexado de una cadena de caracteres en Python.

Elaboración propia. Clic para ampliar.

Concatenación

Operador: +
Permite unir dos o más cadenas en una sola.

nombre = "Lucía"
saludo = "Hola, " + nombre
print(saludo)   # Resultado: Hola, Lucía

Repetición

Operador: *
Permite repetir una cadena un número determinado de veces.

eco = "Python " * 3
print(eco)   # Resultado: Python Python Python

Indexación

Operador: []
Permite acceder a un carácter concreto de una cadena indicando su posición (empezando en 0).

texto = "Python"
print(texto[0])   # Resultado: P
print(texto[5])   # Resultado: n

Trocear una cadena (Slicing)

Operador: [inicio:fin:paso]
Permite extraer una parte o “rebanada” (en la documentación oficial en inglés se usa el término slice) de la cadena indicando posiciones de inicio, fin y un paso opcional. Las principales formas de uso son:

  • [:] → copia toda la cadena.
  • [inicio:] → desde inicio hasta el final.
  • [:fin] → desde el inicio hasta fin - 1.
  • [inicio:fin] → desde inicio hasta fin - 1.
  • [inicio:fin:paso] → permite indicar un salto o paso entre caracteres.
frase = "El conocimiento es poder"

print(frase[:])        # Resultado: El conocimiento es poder
print(frase[3:15])     # Resultado: conocimiento
print(frase[:2])       # Resultado: El
print(frase[3:15:2])   # Resultado: oncmine

Longitud

Función: len()
Devuelve la cantidad de caracteres de una cadena.

mensaje = "Hola mundo"
print(len(mensaje))   # Resultado: 10

Búsqueda

Operadores y métodos: in, find()
Permite comprobar o localizar texto dentro de una cadena.

frase = "Aprender Python es divertido"
print("Python" in frase)       # Resultado: True
print(frase.find("Python"))    # Resultado: 9

División

Método: split()
Se utiliza para dividir una cadena en partes a partir de un separador, devolviendo una lista.

texto = "rojo,verde,azul"
colores = texto.split(",")
print(colores)   # Resultado: ['rojo', 'verde', 'azul']

Otras operaciones útiles

Python ofrece muchas más operaciones con cadenas. En la siguiente tabla se muestran algunas de las más comunes:

Función o método Descripción
upper() Convierte todos los caracteres a mayúsculas.
lower() Convierte todos los caracteres a minúsculas.
capitalize() Convierte la primera letra a mayúscula.
strip() Elimina espacios en blanco al inicio y al final.
replace(a, b) Reemplaza todas las apariciones de a por b.
startswith() / endswith() Comprueban si una cadena comienza o termina con un texto concreto.
join() Une elementos de una lista en una sola cadena, usando un separador.

Caso practico

Un palíndromo es una palabra, frase o número que se lee igual de izquierda a derecha que de derecha a izquierda. Por ejemplo, "radar" o "reconocer".

Antes de comprobar si una cadena es un palíndromo, es útil aprender a invertir una cadena de texto. Esto consiste en generar una nueva cadena cuyos caracteres aparecen en orden inverso al de la original.

Por ejemplo, si se introduce "Python", la cadena invertida será "nohtyP".

Nota: Esta operación de inversión será la base para determinar posteriormente si la cadena introducida es un palíndromo.
