8.3.5 Diccionarios por comprensión

FPD - Free Text

De manera análoga a las listas por comprensión, es posible crear diccionarios utilizando llaves { } y comprensiones. Esto permite generar un diccionario de forma concisa y clara.

Representación conceptual de un diccionario por comprensión.

Elaboración propia. Clic para ampliar.

Por ejemplo, se puede crear un diccionario donde las claves sean palabras y los valores su longitud:

words = ('moon', 'star', 'planet', 'comet')
word_lengths = {word: len(word) for word in words}
print(word_lengths)
# {'moon': 4, 'star': 4, 'planet': 6, 'comet': 5}

También se pueden aplicar condiciones para filtrar elementos. Por ejemplo, incluir únicamente palabras que no comiencen con una vocal:

words = ('moon', 'star', 'planet', 'earth')
filtered_lengths = {w: len(w) for w in words if w[0] not in 'aeiou'}
print(filtered_lengths)
# {'moon': 4, 'star': 4, 'planet': 6}

Nota: Los diccionarios por comprensión permiten combinar iteraciones y condiciones en una sola expresión, facilitando la creación de diccionarios de manera eficiente.

También es posible combinar comprensiones con funciones como str.upper() o str.lower() para transformar claves o valores mientras se construye el diccionario.

A Step Ahead

Para profundizar en este tema, se puede consultar el PEP-274, que describe ejemplos y casos de uso de diccionarios por comprensión.
