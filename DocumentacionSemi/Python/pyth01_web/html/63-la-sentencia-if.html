6.3 La sentencia if

FPD - Free Text

La sentencia condicional en Python es if. Para escribirla, se debe añadir una expresión de comparación seguida de dos puntos al final de la línea. Por ejemplo:

temperature = 37

if temperature > 36:
    print("Alerta: temperatura elevada")

Nota: En Python no es necesario incluir paréntesis ( ) al escribir condiciones. A veces se usan por claridad o para establecer prioridades.

Si la condición no se cumple, es posible controlar el caso usando la sentencia else. Por ejemplo:

temperature = 22

if temperature > 36:
    print("Alerta: temperatura elevada")
else:
    print("Temperatura normal")

Python permite condiciones anidadas, es decir, condiciones dentro de otras condiciones:

temperature = 25

if temperature < 20:
    if temperature < 10:
        print("Nivel azul")
    else:
        print("Nivel verde")
else:
    if temperature < 30:
        print("Nivel naranja")
    else:
        print("Nivel rojo")

Para simplificar condiciones anidadas consecutivas de else + if, se puede utilizar la sentencia elif:

temperature = 25

if temperature < 20:
    if temperature < 10:
        print("Nivel azul")
    else:
        print("Nivel verde")
elif temperature < 30:
    print("Nivel naranja")
else:
    print("Nivel rojo")

Caso practico

Vamos a practicar el uso de condicionales if, elif y else. Supongamos que queremos clasificar temperaturas en distintos niveles de alerta:

  • Temperatura menor que 10 → Nivel azul
  • Temperatura entre 10 y 19 → Nivel verde
  • Temperatura entre 20 y 29 → Nivel naranja
  • Temperatura 30 o mayor → Nivel rojo

Escribe un programa que lea un valor de temperatura por teclado y muestre el nivel correspondiente.
