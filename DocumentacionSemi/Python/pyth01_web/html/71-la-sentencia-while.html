7.1 La sentencia while

FPD - Free Text

La sentencia while permite ejecutar repetidamente un bloque de código mientras se cumpla una condición. Este tipo de estructura de repetición es útil cuando no se conoce de antemano cuántas veces será necesario repetir el código, pero sí la condición que debe mantenerse.

Nota: Si la condición nunca deja de cumplirse, el bucle while se ejecutará de forma infinita. Por ello, es fundamental asegurarse de que la condición pueda cambiar durante la ejecución del bucle.

Ejemplo de uso básico:

value = 1

while value <= 4:
    print(value)
    value += 1

Elaboración propia. Clic para ampliar.

Explicación: La condición del bucle se comprueba en cada repetición. En este caso, se verifica que la variable value sea menor o igual a 4. Dentro del cuerpo del bucle, la variable se incrementa en 1 unidad. Cuando value supera 4, la condición deja de cumplirse y el bucle finaliza.

Romper un bucle while

Python permite finalizar un bucle antes de que se cumpla la condición de parada mediante la instrucción break. Por ejemplo, para buscar el primer múltiplo de 3 descendiendo desde 20:

num = 20
while num >= 1:
    if num % 3 == 0:
        print(num)
        break
    num -= 1

Explicación: La instrucción break finaliza el bucle una vez encontrado el primer múltiplo de 3. Si no se hubiera encontrado, el bucle habría continuado decrementando num hasta llegar a 0, momento en que la condición del while sería falsa.

Uso de if-else con while

La cláusula else se ejecuta solo si el bucle termina normalmente, es decir, sin interrupción por break. Esto permite diferenciar entre "encontrado" y "no encontrado":

num = 8
while num >= 1:
    if num % 9 == 0:
        print(f"{num} is a multiple of 9!")
        break
    num -= 1
else:
    print("No multiples of 9 found!")

Explicación: Como no existe ningún múltiplo de 9 en el rango [1, 8], el bucle finaliza normalmente y se ejecuta la cláusula else, mostrando el mensaje de que no se encontraron múltiplos.

Bucle infinito controlado

Se puede usar while True para crear un bucle infinito que se interrumpe manualmente con break:

numero = 0
while True:
    numero = int(input("Introduce un número positivo (0 para salir): "))
    if numero == 0:
        print("Bucle terminado")
        break
    print(f"Has introducido {numero}")

Explicación: Este patrón es útil cuando no se conoce de antemano el número de iteraciones. El bucle se interrumpe dinámicamente mediante la instrucción break en función de la entrada del usuario.

Combinación de condiciones lógicas

Se pueden combinar condiciones más complejas dentro del while:

saldo = 100
retiro = 20

while saldo >= retiro:
    print(f"Retiro de {retiro} realizado. Saldo actual: {saldo}")
    saldo -= retiro
print("Saldo insuficiente para realizar más retiros")

Explicación: El bucle se ejecuta mientras saldo >= retiro. En cada iteración se descuenta el retiro del saldo. Cuando saldo es menor que retiro, la condición deja de cumplirse y el bucle termina automáticamente.

Uso de while con incrementos y decrementos seguros

Es fundamental garantizar que las variables que controlan la condición del bucle se actualicen correctamente en cada iteración. Esto evita bucles infinitos accidentales y asegura que la condición pueda dejar de cumplirse en algún momento.

Bucle infinito intencionado

El patrón while True es útil cuando no se conoce el número de iteraciones y se quiere un control dinámico mediante break. Se emplea frecuentemente en menús interactivos, programas que esperan entrada del usuario o servidores que procesan solicitudes continuamente.

Nota final

Al dominar while, break y else, se puede controlar con precisión la ejecución repetitiva en Python y diferenciar entre finalización normal y finalización anticipada de un bucle.

A Piece of Advice

La sentencia while es una de las estructuras de repetición más importantes en Python. Permite ejecutar un bloque de código mientras se cumpla una condición y se puede combinar con break, continue y else para un control más preciso del flujo de ejecución.
