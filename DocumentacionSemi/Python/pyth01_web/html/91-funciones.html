9.1 Funciones

FPD - Free Text

En Python, las funciones permiten encapsular bloques de código que realizan una tarea específica. Esto facilita la modularidad del programa, la reutilización del código y su mantenimiento.

Elaboración propia. Clic para ampliar.

Definir una función se realiza mediante la palabra clave def, seguida del nombre de la función y paréntesis que pueden incluir parámetros. La sintaxis completa es:

def nombre_funcion(parámetro1, parámetro2, ...):
    # cuerpo de la función
    instrucciones

Por ejemplo, una función sencilla que saluda se define así:

def saludar():
    print("¡Hola a todos!")

La función se llama utilizando su nombre seguido de paréntesis:

saludar()
# Salida: ¡Hola a todos!

Se pueden definir funciones con parámetros para recibir información y usarla dentro del bloque de código:

def saludar_persona(nombre):
    print(f"¡Hola, {nombre}!")

def sumar(a, b):
    return a + b

Se llaman pasando los argumentos correspondientes, que son los valores reales que se asignan a los parámetros:

saludar_persona("Ana")
# Salida: ¡Hola, Ana!

resultado = sumar(5, 7)
print(resultado)
# Salida: 12

En resumen, los parámetros son las variables definidas en la función para recibir datos, mientras que los argumentos son los valores concretos que se pasan al llamar a la función.

Veracidad

Las funciones pueden devolver valores utilizando la palabra clave return. Si no se devuelve nada explícitamente, Python retorna None.

def sumar(a, b):
    return a + b

resultado = sumar(3, 5)
print(resultado)
# Salida: 8

Parámetros y argumentos

Los parámetros son variables definidas en la declaración de la función, mientras que los argumentos son los valores que se pasan al llamar la función.

Argumentos nominales

Se pueden pasar los argumentos indicando explícitamente el nombre del parámetro:

def presentar(nombre, edad):
    print(f"{nombre} tiene {edad} años")

presentar(nombre="Ana", edad=25)
# Salida: Ana tiene 25 años

Argumentos posicionales y nominales

Es posible combinar ambos tipos de argumentos, siempre indicando primero los posicionales:

presentar("Luis", edad=30)
# Salida: Luis tiene 30 años

Parámetros por defecto

Se pueden definir valores por defecto para los parámetros, de modo que no sea obligatorio proporcionarlos al llamar la función:

def presentar(nombre, edad=18):
    print(f"{nombre} tiene {edad} años")

presentar("Marta")
# Salida: Marta tiene 18 años

Modificando parámetros mutables

Si un parámetro es un objeto mutable, como una lista o un diccionario, las modificaciones realizadas dentro de la función afectan al objeto original:

def agregar_item(lista, item):
    lista.append(item)

mi_lista = [1, 2, 3]
agregar_item(mi_lista, 4)
print(mi_lista)
# Salida: [1, 2, 3, 4]

Para evitar modificar el objeto original, se puede trabajar con una copia del mismo dentro de la función.

Avanzando con funciones en Python

Empaquetar y desempaquetar argumentos

Python permite recibir un número variable de argumentos mediante el empaquetado con * para tuplas y ** para diccionarios. Esto facilita trabajar con funciones flexibles que no requieren un número fijo de parámetros.

def mostrar_numeros(*numeros):
    print(numeros)

mostrar_numeros(1, 2, 3, 4)
# Salida: (1, 2, 3, 4)

De manera análoga, los argumentos pueden desempaquetarse al llamar a la función:

nums = (10, 20, 30)
mostrar_numeros(*nums)
# Salida: (10, 20, 30)

Empaquetar y desempaquetar argumentos nominales

Los argumentos nominales se pueden empaquetar en un diccionario usando **kwargs y desempaquetar al llamar a la función:

def mostrar_info(**info):
    for clave, valor in info.items():
        print(f"{clave}: {valor}")

mostrar_info(nombre="Ana", edad=25)
# Salida:
# nombre: Ana
# edad: 25

data = {"nombre": "Luis", "edad": 30}
mostrar_info(**data)

Forzando modo de paso de argumentos

Python permite definir parámetros que sólo pueden recibir argumentos por posición o por nombre. Esto ayuda a que las funciones sean más claras y eviten errores de llamada.

Argumentos sólo nominales

Se colocan después de un * en la definición de la función:

def registrar_usuario(*, nombre, edad):
    print(f"{nombre} tiene {edad} años")

registrar_usuario(nombre="Marta", edad=28)
# Salida: Marta tiene 28 años
# registrar_usuario("Marta", 28)  -> Error

Fijando argumentos posicionales y nominales

Se pueden obligar algunos parámetros a ser posicionales, mientras que otros sólo se pasan por nombre:

def ejemplo(a, b, *, c, d):
    print(a, b, c, d)

ejemplo(1, 2, c=3, d=4)
# Salida: 1 2 3 4

Argumentos mutables e inmutables

Cuando se pasan argumentos mutables (listas, diccionarios), las funciones pueden modificar el objeto original. Los argumentos inmutables (números, cadenas, tuplas) no se modifican dentro de la función.

def modificar_lista(lista):
    lista.append(99)

mi_lista = [1, 2]
modificar_lista(mi_lista)
print(mi_lista)
# Salida: [1, 2, 99]

def sumar_valor(x):
    x += 5
    return x

num = 10
nuevo = sumar_valor(num)
print(num, nuevo)
# Salida: 10 15

Funciones como parámetros

En Python, las funciones son objetos de primera clase, por lo que pueden pasarse como argumentos a otras funciones:

def aplicar(func, valor):
    return func(valor)

def cuadrado(x):
    return x ** 2

resultado = aplicar(cuadrado, 5)
print(resultado)
# Salida: 25

Esto permite crear funciones más generales y reutilizables, combinando comportamientos mediante parámetros de tipo función.

Documentación

En Python, la documentación es fundamental para que el código sea comprensible, mantenible y reutilizable. Documentar correctamente funciones, clases y módulos permite a otros desarrolladores, o al propio autor, entender rápidamente qué hace cada parte del programa.

La forma estándar de documentar una función o clase es mediante docstrings, que son cadenas de texto multilínea incluidas justo después de la definición.

def saludar(nombre):
    """
    Saluda a la persona cuyo nombre se recibe como parámetro.
    
    Parámetros:
    nombre (str): El nombre de la persona a saludar.
    
    Retorna:
    None
    """
    print(f"¡Hola, {nombre}!")

El docstring puede incluir información sobre los parámetros de la función, los valores de retorno y cualquier detalle adicional que sea útil para entender su funcionamiento. Este tipo de documentación puede consultarse en tiempo de ejecución mediante la función help():

help(saludar)

Para proyectos más grandes, se puede utilizar Sphinx, una herramienta que genera documentación automática en HTML, PDF u otros formatos a partir de los docstrings y comentarios en el código.

Python también permite utilizar anotaciones de tipos para indicar el tipo de los parámetros y del valor de retorno, mejorando la legibilidad y ayudando a herramientas de análisis estático:

def sumar(a: int, b: int) -> int:
    """
    Suma dos números enteros y devuelve el resultado.
    """
    return a + b

Los docstrings pueden documentar también valores por defecto de los parámetros:

def saludar_persona(nombre: str = "Invitado"):
    """
    Saluda a una persona. Si no se proporciona nombre, se utiliza 'Invitado'.
    """
    print(f"¡Hola, {nombre}!")

De este modo, los parámetros por defecto se explican en la documentación, lo que facilita su comprensión y evita errores al llamar a la función.
