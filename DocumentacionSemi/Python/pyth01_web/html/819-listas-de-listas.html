8.1.9 Listas de listas

FPD - Free Text

En Python, una lista de listas es una lista cuyos elementos también son listas. Cada sublista puede contener información relacionada, lo que permite organizar los datos en forma de tabla o registros.

Crear una lista de listas

Supongamos que queremos representar información de tres personas: su nombre, edad y ciudad de residencia:

people = [
    ["Pedro", 29, "Barcelona"],
    ["Ana", 34, "Madrid"],
    ["Luis", 22, "Valencia"]
]

# Acceso a elementos
people[0]       # ['Pedro', 29, 'Barcelona'], primera persona
people[1][2]    # 'Madrid', ciudad de la segunda persona
people[-1][-1]  # 'Valencia', ciudad de la última persona

Manipulación de listas de listas

Se pueden modificar valores individuales accediendo con dos índices:

people[0][1] = 30   # Cambiamos la edad de Pedro
people
# [['Pedro', 30, 'Barcelona'], ['Ana', 34, 'Madrid'], ['Luis', 22, 'Valencia']]

Utilizando listas de listas en Python

Podemos recorrer las listas de listas con bucles anidados para procesar o mostrar la información:

for i, person in enumerate(people):
    for j, value in enumerate(person):
        print(f"Persona {i+1}, dato {j+1}: {value}")

Ejemplo práctico

Imaginemos que queremos imprimir solo los nombres de todas las personas:

for person in people:
    print(person[0])
# Salida:
# Pedro
# Ana
# Luis

Consejo: Las listas de listas permiten organizar información de manera estructurada. Si se trabaja con grandes volúmenes de datos, es recomendable usar librerías como pandas o NumPy para optimizar rendimiento y manejo de tablas.
