8.2.5 Tupas vs. Listas

FPD - Free Text

Aunque las tuplas y las listas puedan parecer estructuras de datos muy similares, existen diferencias importantes entre ambas:

  • Mutabilidad: Las listas son mutables, es decir, sus elementos pueden modificarse, añadirse o eliminarse. Por el contrario, las tuplas son inmutables, lo que significa que una vez creadas no se pueden cambiar.

Elaboración propia. Clic para ampliar.

  • Operaciones disponibles: Muchas operaciones de las listas no están disponibles para tuplas, como append(), remove(), clear(), sort() o reverse().
  • Uso como claves de diccionario: Solo los elementos inmutables pueden ser usados como claves de un diccionario. Por ello, las tuplas pueden servir como claves mientras que las listas no.
  • Optimización de memoria: Las tuplas ocupan menos espacio en memoria que las listas de igual tamaño, por lo que resultan más eficientes si no necesitamos modificar sus elementos.
# Ejemplo de lista mutable
fruits_list = ['Manzana', 'Banana', 'Cereza']
fruits_list.append('Melón')
print(fruits_list)
# Salida: ['Manzana', 'Banana', 'Cereza', 'Melón']

# Ejemplo de tupla inmutable
fruits_tuple = ('Manzana', 'Banana', 'Cereza')
# fruits_tuple.append('Melón')  # Esto daría un error
print(fruits_tuple)
# Salida: ('Manzana', 'Banana', 'Cereza')

Otras ventajas de las tuplas:

  1. Protección frente a cambios indeseados: Al ser inmutables, es imposible que un elemento se modifique accidentalmente durante la ejecución del programa.
  2. Hashables: Las tuplas pueden usarse como claves en diccionarios, a diferencia de las listas.
  3. Namedtuples: Python ofrece namedtuple como alternativa ligera a los objetos, combinando la inmutabilidad de las tuplas con nombres para sus campos.
from collections import namedtuple

# Definición de una tupla nombrada
Person = namedtuple('Person', ['name', 'age', 'city'])
p1 = Person('Ana', 28, 'Madrid')
print(p1.name, p1.age, p1.city)
# Salida: Ana 28 Madrid

En resumen, se pueden considerar las tuplas como una versión más segura y eficiente de las listas cuando no necesitamos modificar los elementos y queremos aprovechar sus propiedades como inmutables y hashables.

Ejemplos de propiedades avanzadas de tuplas

1. Tuplas como claves de diccionarios (hashables)

Al ser inmutables, las tuplas pueden utilizarse como claves en un diccionario, mientras que las listas no:

# Diccionario con tuplas como claves
coordinates_dict = {
    (40.4168, -3.7038): 'Madrid',
    (41.3851, 2.1734): 'Barcelona',
    (37.3891, -5.9845): 'Sevilla'
}

# Accedemos a un valor usando una tupla como clave
print(coordinates_dict[(41.3851, 2.1734)])
# Salida: 'Barcelona'

# Intentar usar una lista como clave generaría un error
# coordinates_dict[[40.4168, -3.7038]] = 'Madrid'  # TypeError

2. Namedtuples: tuplas con nombres para sus campos

El módulo collections proporciona namedtuple, que permite crear tuplas inmutables con campos accesibles por nombre, combinando claridad y eficiencia:

from collections import namedtuple

# Definimos una namedtuple llamada 'Person'
Person = namedtuple('Person', ['name', 'age', 'city'])

# Creamos instancias
p1 = Person('Ana', 28, 'Madrid')
p2 = Person('Luis', 35, 'Barcelona')

# Accedemos a los campos por nombre
print(p1.name, p1.age, p1.city)
# Salida: Ana 28 Madrid

print(p2.name, p2.age, p2.city)
# Salida: Luis 35 Barcelona

Nota: Las namedtuple son muy útiles para representar registros de datos sin necesidad de definir una clase completa, manteniendo la inmutabilidad y claridad del código.

Caso practico

Se desea almacenar información sobre las edades de un grupo de personas. Se quiere comprobar cómo se puede modificar la información en una lista y en una tupla, y cómo se puede acceder a los elementos en ambos casos.
