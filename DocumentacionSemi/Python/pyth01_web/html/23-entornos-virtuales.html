2.3 Entornos virtuales

FPD - Free Text

Cuando se trabaja en distintos proyectos, no todos requieren los mismos paquetes ni la misma versión de Python. Gestionar estas diferencias a nivel global puede resultar complejo, por lo que surge el concepto de entornos virtualesEspacio aislado en un sistema informático que permite ejecutar programas y gestionar sus dependencias de manera independiente del resto del sistema, evitando conflictos con otras aplicaciones o configuraciones.. Estos entornos permiten establecer qué versión de Python se utilizará y qué paquetes se instalarán en cada proyecto, manteniendo el sistema principal limpio y ordenado.

Crear un entorno virtual con venv

La manera más sencilla de crear un entorno virtual utilizando el módulo incluido en Python 3 es la siguiente:

En Linux/macOS:

$ cd myproject
$ python3 -m venv .venv
$ source .venv/bin/activate
(.venv) $

En Windows (CMD):

> cd myproject
> python -m venv .venv
> .venv\Scripts\activate
(.venv) >

En Windows (PowerShell):

> cd myproject
> python -m venv .venv
> .\.venv\Scripts\Activate.ps1
(.venv) >
  • Línea 1: Entrar en la carpeta del proyecto.
  • Línea 2: Crear la carpeta .venv con los archivos que constituyen el entorno virtual.
  • Línea 3: Activar el entorno virtual. El prompt cambia para indicar que el entorno virtual está activo ((.venv) $ o (.venv) >).

Una vez activo, se puede instalar un paquete, por ejemplo:

Crear un entorno virtual con virtualenv

Para proyectos más avanzados o compatibles con versiones antiguas de Python, se puede utilizar virtualenv. Primero se instala la herramienta:

$ pip install virtualenv

A continuación se crea y activa el entorno virtual:

En Linux/macOS:

$ cd myproject
$ virtualenv .venv
$ source .venv/bin/activate
(.venv) $

En Windows (CMD):

> cd myproject
> virtualenv .venv
> .venv\Scripts\activate
(.venv) >

Una vez activo, se puede instalar un paquete de la misma manera que con venv.

Los entornos virtuales permiten trabajar de forma organizada en Python, manteniendo separadas las dependencias de cada proyecto y evitando conflictos entre versiones de paquetes. Tanto venv como virtualenv cumplen esta función, siendo virtualenv más flexible y compatible con versiones antiguas.

Gestión avanzada con virtualenvwrapper

La herramienta virtualenvwrapper funciona sobre virtualenv y facilita la administración de entornos virtuales. Se instala mediante:

$ pip install virtualenvwrapper

Algunos comandos básicos incluyen:

  • mkvirtualenv env1: crea un entorno virtual llamado env1.
  • workon env1: activa el entorno virtual env1.
  • deactivate: desactiva el entorno virtual activo.
  • lssitepackages: lista los paquetes instalados en el entorno virtual activo.
  • pip install paquete: instala un paquete dentro del entorno virtual activo.

Estas herramientas permiten gestionar de forma eficiente las dependencias de cada proyecto y garantizan que los proyectos puedan mantenerse actualizados sin afectar al resto del sistema.
