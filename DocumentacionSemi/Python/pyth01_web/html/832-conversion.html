8.3.2 Conversión

FPD - Free Text

En Python es posible convertir otros tipos de datos en un diccionario utilizando la función dict(). Para que la conversión sea válida, el iterable debe contener elementos con una estructura de dos elementos, donde el primero será la clave y el segundo el valor.

Representación gráfica de la conversión de una lista de 2 tuplas en un diccionario de 2 pares clave: valor.

Elaboración propia. Clic para ampliar.

# Diccionario a partir de una lista de tuplas
dict([('x', 10), ('y', 20)])
# {'x': 10, 'y': 20}

# Diccionario a partir de una tupla de listas
dict((['a', 1], ['b', 2]))
# {'a': 1, 'b': 2}

# Diccionario a partir de una lista de listas
dict([['name', 'Alice'], ['age', 30]])
# {'name': 'Alice', 'age': 30}

Diccionario vacío

Si se utiliza dict() sin argumentos, se obtiene un diccionario vacío:

empty_dict = dict()
empty_dict
# {}

Truco: Para crear un diccionario vacío, se recomienda usar {} en lugar de dict(), ya que es más pitónico y ofrece un mejor rendimiento.

Creación de diccionarios con dict()

Es posible crear un diccionario pasando claves y valores directamente como argumentos de la función dict(), siempre que las claves sean identificadores válidos de Python (sin espacios ni caracteres especiales):

person = dict(
    name='Alice',
    surname='Smith',
    profession='Engineer'
)
person
# {'name': 'Alice', 'surname': 'Smith', 'profession': 'Engineer'}

Nota: No se permiten claves con espacios o caracteres no válidos:

person = dict(
    first name='Alice'  # Esto produce un error de sintaxis
)
# SyntaxError: invalid syntax

Se puede crear un diccionario especificando sus claves y un único valor de «relleno» mediante dict.fromkeys():

vowels = dict.fromkeys('aeiou', 0)
vowels
# {'a': 0, 'e': 0, 'i': 0, 'o': 0, 'u': 0}

Nota: La función fromkeys() acepta cualquier iterable para generar las claves, y asigna el mismo valor a todas ellas.
