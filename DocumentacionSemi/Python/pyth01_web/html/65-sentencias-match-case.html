6.5 Sentencias match-case

FPD - Free Text

Una de las novedades más relevantes de Python 3.10 fue el Structural Pattern Matching, que introdujo una nueva sentencia condicional. Esta sentencia puede compararse con la sentencia switch presente en otros lenguajes de programación.

Comparando valores

En su forma más básica, el pattern matching permite comparar un valor con una serie de literales, de manera similar a múltiples sentencias if encadenadas. Por ejemplo:

color = "#FF0000"

match color:
    case "#FF0000":
        print("Rojo")
    case "#00FF00":
        print("Verde")
    case "#0000FF":
        print("Azul")

Nota: Si el valor comparado no se encuentra entre los patrones disponibles, no se ejecuta ninguna acción. Para controlar este caso, se puede usar el subguión _ como patrón por defecto:

color = "#AF549B"

match color:
    case "#FF0000":
        print("Rojo")
    case "#00FF00":
        print("Verde")
    case "#0000FF":
        print("Azul")
    case _:
        print("Unknown color!")

Patrones avanzados

La sentencia match-case permite deconstruir estructuras de datos, capturar elementos o mapear valores. Por ejemplo, para determinar la dimensión de un punto representado por una tupla:

point = (2, 5)

match point:
    case (x, y):
        print(f"({x},{y}) is in plane")
    case (x, y, z):
        print(f"({x},{y},{z}) is in space")

También es posible restringir los patrones a valores enteros:

point = (2, 5)

match point:
    case (int(), int()):
        print(f"{point} is in plane")
    case (int(), int(), int()):
        print(f"{point} is in space")
    case _:
        print("Unknown!")

Para calcular la distancia del punto al origen sin conocer si se encuentra en el plano o en el espacio:

point = (8, 3, 5)

match point:
    case (int(x), int(y)):
        dist_to_origin = (x ** 2 + y ** 2) ** 0.5
    case (int(x), int(y), int(z)):
        dist_to_origin = (x ** 2 + y ** 2 + z ** 2) ** 0.5
    case _:
        print("Unknown!")

Validación de estructuras de diccionario

La sentencia match-case permite verificar la estructura de un bloque de autenticación definido mediante diccionarios, asegurando que los valores cumplan los formatos esperados:

auths = [
    {"username": "sdelquin", "password": "1234"},
    {"email": "sdelquin@gmail.com", "token": "4321"},
    {"email": "test@test.com", "password": "ABCD"},
    {"username": "sdelquin", "password": 1234}
]

for auth in auths:
    match auth:
        case {"username": str(username), "password": str(password)}:
            print("Authenticating with username and password")
            print(f"{username}: {password}")
        case {"email": str(email), "token": str(token)}:
            print("Authenticating with email and token")
            print(f"{email}: {token}")
        case _:
            print("Authenticating method not valid!")
    print("---")

Uso de cláusulas guarda y operador OR

Se puede determinar si una persona puede beber alcohol según su edad, utilizando cláusulas guarda y el operador OR:

age = 21

match age:
    case 0 | None:
        print("Not a person")
    case n if n < 17:
        print("Nope")
    case n if n < 22:
        print("Not in the US")
    case _:
        print("Yes")
