8.1.1 Creando listas

FPD - Free Text

Una lista en Python está compuesta por cero o más elementos, que deben escribirse separados por comas y encerrados entre corchetes. Esta estructura permite almacenar información de manera ordenada y flexible.

empty_list = []
programming_languages = ["Python", "Go", "Java"]
primes = [2, 3, 5, 7, 11, 13]
mixed_data = ["Gran Canaria", {"weather": "sunny", "temperature": 27}, 5821, (28.12345, -15.67890)]

Representación gráfica de la lista creada mediante la instrucción programming_languages = ["Python", "Java", "C", "JavaScript", "PHP", "C++"]

Nota: Las listas pueden contener elementos de distintos tipos, incluyendo cadenas de texto, números, diccionarios, tuplas o incluso otras listas. Esto las convierte en estructuras de datos muy versátiles para almacenar y organizar información heterogénea.

  • Lista vs Array: Una lista en Python es una estructura de datos abstracta que permite almacenar una colección ordenada de elementos. Cada elemento puede ser de un tipo distinto, y la lista puede crecer o reducirse dinámicamente durante la ejecución del programa.
  • Un array, en cambio, es una estructura de datos de tamaño fijo en la que todos los elementos deben ser del mismo tipo. Lenguajes como Java o C++ implementan arrays clásicos que requieren conocer su tamaño y tipo al momento de la creación.

Comparando ambos conceptos: en Python, las listas sustituyen a los arrays clásicos en la mayoría de los casos, ofreciendo flexibilidad y heterogeneidad de tipos. Esto hace que sean muy versátiles para trabajar con colecciones de datos, mientras que en Java o C++ los arrays son más rígidos y requieren planificación previa del tamaño y tipo de datos.

Una lista es un tipo abstracto de datos que permite almacenar múltiples elementos de manera ordenada y dinámica.

En Python, las listas se crean usando corchetes y separando los elementos con comas: ejemplo = [1, 2, 3, 'Python'].

Un array es una estructura de datos similar a una lista, pero con un tamaño fijo y todos los elementos del mismo tipo, común en lenguajes como Java o C++.

La principal diferencia con otros lenguajes es que en Python las listas son dinámicas , mientras que los arrays son estáticos .

Por ejemplo, se puede crear una lista vacía: vacia = [] y añadir elementos en cualquier momento.
