4. Números

Situation

En TechServe, Marta continúa guiando al equipo en su proceso de formación en Python. Después de familiarizarse con las variables y los tipos básicos de datos, ha llegado el momento de centrarse en los números, fundamentales para cualquier tarea de administración de sistemas.

El objetivo de esta sesión es que el equipo aprenda a utilizar valores numéricos para representar datos reales del entorno de trabajo: el número de servidores activos, el porcentaje de uso de CPU o memoria, los tiempos de respuesta de los servicios o el estado lógico (activo o inactivo) de un sistema determinado.

Marta explica que Python distingue entre enteros, flotantes y booleanos, y que dominar su uso permitirá desarrollar scripts capaces de realizar cálculos, generar informes y tomar decisiones automáticas en función de los resultados obtenidos.

Con esta base, el equipo de TechServe podrá avanzar hacia el siguiente paso: integrar estos datos numéricos en programas más complejos que controlen y supervisen la infraestructura de la empresa de forma totalmente automatizada.

FPD - Free Text

En Python, los números representan una de las categorías de datos fundamentales. Se utilizan en prácticamente todos los programas, ya sea para realizar cálculos, analizar resultados, controlar procesos o tomar decisiones en función de métricas numéricas. Comprender cómo funcionan y cómo se manipulan es esencial para cualquier desarrollador o administrador de sistemas que desee automatizar tareas con precisión.

Python ofrece tres tipos numéricos principales:

  • Enteros (int): se emplean para representar números sin decimales, positivos o negativos. Son ideales para contar elementos, identificar recursos o controlar iteraciones.
  • Flotantes (float): permiten representar números con decimales, lo que resulta útil cuando se trabaja con medidas, porcentajes o resultados de operaciones que requieren precisión.
  • Booleanos (bool): indican valores de verdad, es decir, True o False. Aunque no parecen números a primera vista, internamente Python los trata como tales, siendo True equivalente a 1 y False a 0.

Todos estos tipos pueden coexistir y combinarse en expresiones, siempre que se tenga en cuenta su naturaleza y el tipo de resultado que producen. Además, Python facilita la conversión entre ellos, permitiendo transformar un número entero en flotante o un valor booleano en entero, según las necesidades del programa.

En Python, no es necesario declarar el tipo de dato de una variable antes de usarla. El propio intérprete infiere el tipo en función del valor asignado, lo que simplifica el código y lo hace más legible.

En Python, los números se dividen principalmente en enteros (int) y flotantes (float). Los enteros representan valores sin decimales, mientras que los flotantes permiten trabajar con números que contienen decimales. Además, Python cuenta con el tipo booleano (bool), que indica valores de verdad como True o False.
