8.1.7 Ejecución desde línea de comandos

FPD - Free Text

sys.argv

Cuando se ejecuta un programa Python desde la línea de comandosInterfaz de texto que permite al usuario interactuar con el sistema operativo o programas escribiendo órdenes (comandos) directamente, en lugar de usar una interfaz gráfica., es posible pasarle argumentos que el programa podrá procesar. Para acceder a ellos se utiliza la lista argv del módulo sys. Esta lista contiene todos los argumentos que se pasan al programa:

import sys

# El primer elemento de sys.argv es siempre el nombre del script
script_name = sys.argv[0]

# A continuación se encuentran los argumentos proporcionados en línea de comandos
arg1 = sys.argv[1]        # normalmente una cadena de texto
arg2 = float(sys.argv[2]) # ejemplo de argumento numérico flotante
arg3 = int(sys.argv[3])   # ejemplo de argumento numérico entero
arg4 = sys.argv[4]        # otro argumento de texto

print(f"arg1={arg1}")
print(f"arg2={arg2}")
print(f"arg3={arg3}")
print(f"arg4={arg4}")

En la siguiente imagen se ilustra en un diagrama tabular el acceso a los distintos argumentos de la llamada desde línea de comandos.

Elaboración propia. Clic para ampliar.

Supongamos que guardamos este código en un archivo llamado process_args.py y lo ejecutamos desde la terminal con la siguiente llamada:

$ python3 process_args.py world 12.34 7 "example argument"

La salida producida sería:

arg1='world'
arg2=12.34
arg3=7
arg4='example argument'

Notas importantes

  • El primer elemento sys.argv[0] siempre contiene el nombre del script.
  • Todos los argumentos se reciben como cadenas de texto, por lo que es habitual convertirlos a int, float u otros tipos según sea necesario.
  • Si se intenta acceder a un índice que no existe, Python genera un IndexError.
  • Este enfoque es útil para scripts que necesitan parámetros externos sin modificar el código fuente.
