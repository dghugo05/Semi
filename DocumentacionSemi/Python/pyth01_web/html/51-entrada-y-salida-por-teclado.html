5.1 Entrada y salida por teclado

FPD - Free Text

En Python, la interacción con el usuario se realiza principalmente mediante la entrada y salida de datos. La entrada por teclado permite al programa recibir información del usuario, mientras que la salida muestra resultados o mensajes en pantalla.

Elaboración propia. Clic para ampliar.

La función input() se utiliza para leer datos desde el teclado. Siempre devuelve cadenas de texto, independientemente de lo que el usuario introduzca.

Ejemplo de lectura de datos por teclado:

nombre = input("Introduce tu nombre: ")
print("Hola, " + nombre + "!")

En este ejemplo, el programa solicita al usuario que escriba su nombre y, a continuación, muestra un mensaje personalizado combinando texto literal con la variable nombre.

La función print() permite mostrar información en pantalla. Puede recibir uno o varios valores, separados por comas, y los convierte automáticamente en cadenas si es necesario.

Ejemplo de salida múltiple:

edad = input("Introduce tu edad: ")
ciudad = input("Introduce tu ciudad: ")
print("Hola,", nombre, "tienes", edad, "años y vives en", ciudad + ".")

Además, print() admite parámetros adicionales muy útiles:

1  msg1 = "¡Bienvenido al curso!"
2  msg2 = "Python es fascinante"
3  # Imprimir varias variables
4  print(msg1, msg2)
5  # Salida: ¡Bienvenido al curso! Python es fascinante
6  # Cambiar el separador entre variables
7  print(msg1, msg2, sep=" | ")
8  # Salida: ¡Bienvenido al curso! | Python es fascinante
9  # Cambiar el final del texto
10 print(msg2, end="!!")
11 # Salida: Python es fascinante!!

Línea 4: Podemos imprimir todas las variables que queramos separándolas por comas.
Línea 7: El separador por defecto entre las variables es un espacio, pero se puede cambiar usando sep.
Línea 10: El carácter de final de línea es un salto de línea por defecto, pero se puede modificar usando end.

Cabe destacar que si se necesitan realizar operaciones matemáticas u otros tipos de procesamiento con los datos introducidos, será necesario convertir las cadenas obtenidas mediante input() a otros tipos de datos, como int() o float().
