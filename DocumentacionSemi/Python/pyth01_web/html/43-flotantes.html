4.3 Flotantes

FPD - Free Text

Los números en punto flotante representan valores que incluyen una parte decimal. Se utilizan en Python para representar medidas, cálculos precisos o resultados con fracciones.

Elaboración propia. Clic para ampliar.

>>> 5.0
5.0
>>> 5.
5.0
>>> 0.25
0.25
>>> 3.5e2  # 3.5 * (10 ** 2)
350.0
>>> 1_000.0
1000.0

Nota: Se pueden usar guiones bajos para mejorar la legibilidad de los números flotantes. Además, la notación científica (e) es válida en Python.

Conversión de tipos

En Python existen distintos tipos numéricos y booleanos. Es posible realizar conversiones implícitas o explícitas entre ellos.

Conversión implícita

Cuando se combinan enteros, booleanos y flotantes, Python convierte automáticamente los valores al tipo de mayor rango:

>>> True + 10
11
>>> 5 * False
0
>>> 10 + 3.5
13.5
>>> 7.2 + True
8.2

Nota: Los valores booleanos se tratan como enteros: True = 1 y False = 0.

Conversión explícita

Se pueden utilizar funciones para convertir explícitamente un tipo de dato a otro:

bool(), int(), float()

Ejemplos de conversión explícita:

>>> bool(0)
False
>>> bool(2)
True
>>> int(4.7)
4
>>> float(True)
1.0
>>> float(0)
0.0

Nota: La función int() elimina la parte decimal sin redondear.

Verificación de tipo

Se puede determinar el tipo de una variable usando type() o isinstance():

>>> temperature = 36.6
>>> type(temperature)
<class 'float'>
>>> isinstance(temperature, float)
True
>>> is_active = True
>>> type(is_active)
<class 'bool'>
>>> isinstance(is_active, bool)
True

Errores de aproximación

La aritmética en coma flotante puede generar pequeñas imprecisiones debido al estándar IEEE 754:

>>> result = (20 / 7) * (7 / 20)
0.9999999999999999

Se puede usar la función round() para aproximar a un número específico de decimales:

>>> pi = 3.14159265
>>> round(pi)
3
>>> round(pi, 2)
3.14
>>> round(result, 3)
1.0

Nota: round() aproxima al valor más cercano, mientras que int() siempre trunca hacia abajo.

Límites de un flotante

Los números flotantes en Python sí tienen un límite máximo y mínimo:

>>> import sys
>>> sys.float_info.min
2.2250738585072014e-308
>>> sys.float_info.max
1.7976931348623157e+308

Nota: A diferencia de los enteros, que en Python pueden crecer sin límite, los flotantes están restringidos por su representación interna en memoria.

Operaciones con flotantes

Los números flotantes permiten realizar las mismas operaciones que los enteros, pero con decimales. Algunas operaciones importantes son:

>>> a = 7.5
>>> b = 2.5

# Suma
>>> a + b
10.0

# Resta
>>> a - b
5.0

# Multiplicación
>>> a * b
18.75

# División flotante
>>> a / b
3.0

# División entera (trunca el resultado)
>>> a // b
3.0

# Módulo (resto)
>>> a % b
0.0

# Exponenciación
>>> a ** b
55.90169943749474

Nota: En las operaciones con flotantes, incluso la división entera // devuelve un número en punto flotante si alguno de los operandos es float.

La precisión de las operaciones puede verse limitada por la representación interna de los flotantes, por lo que a veces es recomendable usar round() para redondear resultados.

A Step Ahead

Números en distintas bases

Python permite trabajar con números expresados en diferentes bases, no sólo en la decimal habitual (base 10). Las bases más comunes son:

  • Binario (base 2): Se representa con el prefijo 0b o 0B. Ejemplo: 
    >> binary_number = 0b1010
>>> binary_number
10
  • Octal (base 8): Se representa con el prefijo 0o o 0O. Ejemplo: 
    >> octal_number = 0o12
>>> octal_number
10
  • Hexadecimal (base 16): Se representa con el prefijo 0x o 0X. Ejemplo: 
    >> hex_number = 0xA
>>> hex_number
10

Estos números se pueden convertir entre bases utilizando las funciones bin(), oct() y hex(). Por ejemplo:

>> decimal_number = 15
>>> bin(decimal_number)
'0b1111'
>>> oct(decimal_number)
'0o17'
>>> hex(decimal_number)
'0xf'

Nota: Python interpreta internamente todos los números como enteros o flotantes, independientemente de la base en que se escriban.
