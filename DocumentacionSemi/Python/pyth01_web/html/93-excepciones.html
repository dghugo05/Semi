9.3 Excepciones

FPD - Free Text

Una excepción es un bloque de código que se ejecuta cuando ocurre un error en la ejecución de un programa Python. Ya se han visto algunas excepciones comunes: accesos fuera de rango a listas o tuplas, accesos a claves inexistentes en diccionarios, entre otros. Cuando se ejecuta código que podría fallar, es necesario manejar adecuadamente las excepciones que se generan.

Manejando errores

Si una excepción ocurre y no es capturada en el punto donde se produce, ésta se propaga (burbujea) hasta que es capturada en alguna función que haya hecho la llamada. Si en toda la «pila» de llamadas no existe un control de la excepción, Python muestra un mensaje de error con información adicional:

def intdiv(a, b):
    return a // b

intdiv(10, 0)
# Traceback (most recent call last):
#   File "<stdin>", line 1, in <module>
#   File "<stdin>", line 2, in intdiv
# ZeroDivisionError: integer division or modulo by zero

Para capturar excepciones se utiliza un bloque try-except:

def intdiv(a, b):
    try:
        return a // b
    except:
        print("No se puede dividir entre cero")

intdiv(10, 0)
# Salida: No se puede dividir entre cero

El código dentro de try se ejecuta normalmente si no ocurre ningún error. Si ocurre una excepción, se ejecuta el bloque except.

Consejo: no es recomendable usar except sin especificar el tipo de excepción. Es más seguro capturar tipos concretos para evitar comportamientos inesperados.

Especificando excepciones

Se pueden capturar distintos tipos de excepciones para manejar casos específicos:

def intdiv(a, b):
    try:
        result = a // b
    except TypeError:
        print("Revisar operandos, alguno no es un número")
    except ZeroDivisionError:
        print("No se puede dividir entre cero")
    except Exception:
        print("Ups, ocurrió un error inesperado")

intdiv(10, 0)
# Salida: No se puede dividir entre cero

intdiv(10, "0")
# Salida: Revisar operandos, alguno no es un número

Las excepciones predefinidas de Python se pueden usar directamente sin importarlas.

Cubriendo más casos: else y finally

Python proporciona las cláusulas else y finally. else se ejecuta si no ocurre ninguna excepción, y finally se ejecuta siempre, independientemente de si hay error o no:

valores = [5, 3, 8]
indice_usuario = 5

try:
    resultado = valores[indice_usuario]
except IndexError:
    print("Error: índice fuera de rango")
else:
    print(f"El valor solicitado es: {resultado}")
finally:
    print("Fin del intento")

# Salida:
# Error: índice fuera de rango
# Fin del intento

Excepciones propias

Python permite crear excepciones personalizadas heredando de la clase Exception. Esto es útil para validar condiciones específicas en un programa.

class SoloEnterosError(Exception):
    pass

valores = (4, 7, 2.5, 9)
for v in valores:
    if not isinstance(v, int):
        raise SoloEnterosError(v)
# Traceback (most recent call last):
#   ...
# __main__.SoloEnterosError: 2.5

Se puede personalizar el mensaje de la excepción:

class SoloEnterosError(Exception):
    def __init__(self, valor, mensaje="Este módulo solo funciona con enteros"):
        self.valor = valor
        self.mensaje = mensaje
        super().__init__(self.mensaje)
    def __str__(self):
        return f"{self.valor} -> {self.mensaje}"

raise SoloEnterosError(2.5)
# Traceback (most recent call last):
#   ...
# __main__.SoloEnterosError: 2.5 -> Este módulo solo funciona con enteros

Aserciones

La sentencia assert permite comprobar que se cumplen ciertas condiciones en el programa. Si no se cumplen, se lanza un AssertionError:

resultado = 15
assert resultado > 0
print(resultado)
# Salida: 15

resultado = -5
assert resultado > 0, "El resultado debe ser positivo"
# Traceback (most recent call last):
#   ...
# AssertionError: El resultado debe ser positivo

Si la condición de assert se cumple, el programa continúa normalmente. Si no, se lanza una excepción con un mensaje opcional para indicar la causa.
