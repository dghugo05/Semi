8.2.4 Operaciones con tuplas

FPD - Free Text

Las tuplas permiten realizar la mayoría de las operaciones que se pueden aplicar a listas, excepto aquellas que modifican la tupla «in-situ». Entre las funciones no aplicables se encuentran:

  • reverse()
  • append()
  • extend()
  • remove()
  • clear()
  • sort()

Desempaquetado de tuplas

El desempaquetado es una característica que permite asignar los elementos de una tupla a variables independientes de forma directa, simplificando el acceso a sus valores.

Representación visual del desempaquetado de una tupla.

Elaboración propia. Clic para ampliar.

person = ("Alice", 30, "Madrid")
name, age, city = person
print(name)  # 'Alice'
print(age)   # 30
print(city)  # 'Madrid'

Nota: El desempaquetado es útil cuando se trabaja con funciones que devuelven múltiples valores, como divmod():

quotient, remainder = divmod(17, 4)
print(quotient)   # 4
print(remainder)  # 1

Intercambio de valores

El desempaquetado permite intercambiar el contenido de dos variables de forma directa sin necesidad de una variable auxiliar:

x = 10
y = 25
x, y = y, x
print(x)  # 25
print(y)  # 10

Desempaquetado extendido

Es posible capturar varios elementos de la tupla en una lista mediante el operador *:

ranking = ("Gold", "Silver", "Bronze", "Participant1", "Participant2")
top, *middle, last = ranking
print(top)    # 'Gold'
print(middle) # ['Silver', 'Bronze', 'Participant1']
print(last)   # 'Participant2'

Desempaquetado genérico en tuplas

El desempaquetado de tuplas se puede aplicar de forma genérica, permitiendo asignar los primeros, los últimos y los elementos intermedios a variables de manera flexible:

sample_tuple = ("A", "B", "C", "D", "E")
first, *middle, last = sample_tuple
print(first)  # 'A'
print(middle) # ['B', 'C', 'D']
print(last)   # 'E'

Explicación:

  • first captura el primer elemento de la tupla.
  • *middle captura todos los elementos intermedios en una lista.
  • last captura el último elemento.

Esta forma de desempaquetado es especialmente útil cuando se trabaja con tuplas de longitud variable y se desea procesar los extremos y el contenido intermedio de manera separada.

Consejo: El desempaquetado de tuplas mejora la legibilidad y permite intercambiar valores de manera directa sin usar variables auxiliares, algo que en muchos otros lenguajes requiere pasos adicionales.

Operaciones comunes con tuplas

Operación / Método Descripción Ejemplo
count() Devuelve el número de veces que aparece un valor en la tupla. t = (1,2,2,3); t.count(2) → 2
index() Devuelve el índice de la primera aparición de un valor. t = ("a","b","c"); t.index("b") → 1
len() Devuelve la longitud de la tupla. t = (1,2,3); len(t) → 3
in Comprueba si un elemento está presente en la tupla. 2 in (1,2,3) → True
+ Concatenación de tuplas. (1,2) + (3,4) → (1,2,3,4)
* Repetición de tupla. (1,2)*3 → (1,2,1,2,1,2)
min() / max() Devuelve el mínimo o máximo valor de la tupla. t = (3,7,1); min(t) → 1, max(t) → 7
sum() Suma todos los valores numéricos de la tupla. t = (1,2,3); sum(t) → 6
sorted() Devuelve una lista con los elementos de la tupla ordenados. t = (3,1,2); sorted(t) → [1,2,3]
