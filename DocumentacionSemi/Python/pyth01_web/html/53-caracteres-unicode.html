5.3 Caracteres UNICODE

FPD - Free Text

Python trabaja por defecto con caracteres Unicode. Esto significa que se tiene acceso a la amplia gama de caracteres que ofrece este estándar de codificación.

Elaboración propia. Clic para ampliar.

La función chr() permite representar un carácter a partir de su código:

>>> rocket_code = 0x1F680
>>> rocket = chr(rocket_code)
>>> rocket
'🚀'

Por su parte, la función ord() devuelve el código decimal de un carácter a partir de su representación:

>>> rocket_code = hex(ord(rocket))
>>> rocket_code
'0x1f680'

También se puede utilizar el modificador \N para representar un carácter a partir de su nombre:

>>> '\N{ROCKET}'
'🚀'

Estas funcionalidades permiten trabajar con cualquier carácter Unicode de forma sencilla y flexible en Python.
