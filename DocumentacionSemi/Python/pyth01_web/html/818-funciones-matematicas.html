Funciones matemáticas básicas sobre listas

Python proporciona varias funciones matemáticas que pueden aplicarse directamente sobre listas de valores numéricos.

Entre ellas, destacan las siguientes.

Elaboración propia. Clic para ampliar.

Suma de todos los valores: sum()

data = [4, 7, 1, 9, 6]
total = sum(data)
total
# 27

Mínimo de todos los valores: min()

data = [4, 7, 1, 9, 6]
minimum = min(data)
minimum
# 1

Máximo de todos los valores: max()

data = [4, 7, 1, 9, 6]
maximum = max(data)
maximum
# 9

Ejemplo adicional: Número de elementos de una lista: len()

data = [4, 7, 1, 9, 6]
count = len(data)
count
# 5

Tabla resumen de funciones matemáticas comunes sobre listas

Función Descripción
sum(lista) Devuelve la suma de todos los valores de la lista.
min(lista) Devuelve el valor mínimo de la lista.
max(lista) Devuelve el valor máximo de la lista.
len(lista) Devuelve el número de elementos de la lista.
round(valor, n) Redondea un valor numérico a n decimales.
abs(valor) Devuelve el valor absoluto de un número.
