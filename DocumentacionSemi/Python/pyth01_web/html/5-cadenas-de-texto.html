5. Cadenas de texto

Situation

CC by fauxels

Marta se reúne con su equipo en TechServe para hablar sobre cadenas de texto en Python. Explica que cualquier información escrita, como nombres, direcciones o contraseñas, se representa en Python como cadenas de caracteres.

Les comenta que es importante aprender a manipular, unir y buscar dentro de estas cadenas para poder trabajar con datos de manera efectiva en sus programas.

Con este conocimiento, el equipo estará preparado para procesar información textual correctamente y desarrollar aplicaciones más útiles y completas para la empresa.

FPD - Free Text

En Python, las cadenas de texto (strings) son secuencias de caracteres que permiten almacenar y manipular información textual. Se utilizan para representar nombres, mensajes, direcciones, códigos o cualquier tipo de dato compuesto por caracteres.

Las cadenas pueden crearse de varias formas. La más habitual es mediante comillas simples ('texto') o dobles ("texto") para una sola línea.

Ejemplos de cadenas de una sola línea:
nombre = 'Marta'
mensaje = "Bienvenidos al curso de Python"

También es posible crear cadenas multilínea utilizando tres comillas simples ('''texto''') o tres comillas dobles ("""texto"""), lo que resulta útil para textos largos o documentación dentro del código.

Ejemplo de cadena multilínea:
descripcion = """Python es un lenguaje de programación versátil y potente, utilizado en ciencia de datos, desarrollo web y muchas otras áreas."""

Importante: En Python, las cadenas se tratan como objetos inmutables. Esto significa que, aunque se pueden crear nuevas cadenas a partir de las existentes, una cadena ya definida no puede modificarse directamente.

Esta sección proporciona la base para trabajar con texto en Python, preparando el terreno para aprender operaciones sobre cadenas, entrada y salida de datos por teclado y manejo de caracteres UNICODE en los capítulos siguientes.
