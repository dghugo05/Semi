7.2 La sentencia for

FPD - Free Text

La sentencia for permite ejecutar un bloque de código un número determinado de veces recorriendo cada elemento de una secuencia o de un objeto iterable. Este tipo de bucle se utiliza cuando se conoce de antemano cuántas veces se debe repetir la acción o se quiere iterar sobre todos los elementos de una colección.

Nota: En Python, un iterable es un objeto que puede ser recorrido elemento a elemento, como cadenas de texto, listas, tuplas, diccionarios o ficheros. La sentencia for permite realizar esta acción de manera sencilla y clara.

Ejemplo recorriendo una lista de nombres:

nombres = ["Ana", "Luis", "Marta", "Carlos"]

for nombre in nombres:
    print(f"Hola, {nombre}!")

Explicación: La variable nombre toma cada valor de la lista nombres en cada iteración. Se ejecuta el bloque de código para cada elemento y el bucle termina automáticamente cuando se han recorrido todos los elementos.

Ejemplo recorriendo una cadena de texto:

word = "Python"

for letter in word:
    print(letter)

Explicación: Cada elemento de la cadena word se asigna a la variable letter en cada iteración, permitiendo procesar los caracteres individualmente. La variable puede tener cualquier nombre, pero normalmente se usan nombres en singular.

Romper un bucle for

Al igual que en los bucles while, se puede usar break para finalizar un bucle for antes de recorrer todos los elementos:

word = "Python"

for letter in word:
    if letter == "t":
        break
    print(letter)

Explicación: El bucle se interrumpe cuando la variable letter alcanza el valor "t". Hasta ese momento, se imprime cada letra. Esto permite detener la iteración una vez alcanzado un objetivo.

Secuencias de números con range

Python ofrece la función range() para generar secuencias de números de manera eficiente. Esto es útil para recorrer un conjunto de valores o repetir una acción un número determinado de veces.

Parámetros de range(start, stop, step):

  • start: valor inicial (opcional, por defecto 0).
  • stop: valor final (obligatorio, se llega hasta 1 menos que este valor).
  • step: incremento entre valores (opcional, por defecto 1).

Ejemplos de uso:

# Rango: [0, 1, 2]
for i in range(0, 3):
    print(i)

# Rango: [1, 3, 5]
for i in range(1, 6, 2):
    print(i)

# Rango descendente: [2, 1, 0]
for i in range(2, -1, -1):
    print(i)

Explicación: La función range() devuelve un objeto iterable que genera valores bajo demanda, evitando el consumo innecesario de memoria. Los contadores suelen llamarse i, j, k, aunque se recomienda usar nombres significativos siempre que sea posible.

Repetir una acción sin usar la variable del bucle

Cuando únicamente se desea repetir una acción un número determinado de veces sin usar la variable del bucle, se puede emplear el guión bajo _:

for _ in range(10):
    print("Repite 10 veces!")

Explicación: El guión bajo indica que no se necesita la variable del bucle, facilitando la lectura y comprensión del código. La acción se ejecuta 10 veces exactamente.

Usar condiciones dentro del for

Se pueden combinar estructuras condicionales dentro del bucle for:

numeros = [2, 5, 8, 11, 14]

for n in numeros:
    if n % 2 == 0:
        print(f"{n} es par")
    else:
        print(f"{n} es impar")

Explicación: Cada elemento de la lista se evalúa con un if para determinar si es par o impar, demostrando que dentro de un for se puede aplicar lógica adicional a cada iteración.

Control de flujo: break y continue

for i in range(1, 10):
    if i == 5:
        print("Se alcanzó el número 5, deteniendo bucle")
        break
    if i % 2 == 0:
        continue
    print(f"Número impar: {i}")

Explicación: continue omite la iteración actual para números pares, y break detiene el bucle cuando se alcanza el número 5. Esto permite controlar la ejecución de manera flexible dentro de un for.

Comparativa de bucles: Python vs otros lenguajes

Estructura Python Otros lenguajes (C, C++, Java)
for Itera directamente sobre los elementos de un iterable (cadenas, listas, diccionarios, archivos...). No necesita un contador explícito. Basado en un contador o índice; normalmente requiere inicialización, condición y actualización del índice.
while Ejecuta un bloque mientras la condición sea verdadera. Puede incluir un else que se ejecuta si termina normalmente sin break. Ejecuta un bloque mientras la condición sea verdadera. No existe la cláusula else integrada.
Break / Continue Funciona igual que en otros lenguajes para interrumpir o saltar iteraciones. Mismo comportamiento, aunque la sintaxis puede variar ligeramente.
