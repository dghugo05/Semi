8.3.3 Operaciones con diccionarios

FPD - Free Text

Obtener un elemento

Para obtener un elemento de un diccionario, se indica la clave entre corchetes:

glosario = {
    'efímero': 'Que dura poco tiempo',
    'abigarrado': 'Que tiene muchos colores o elementos juntos',
    'solapado': 'Que actúa con disimulo'
}

glosario['abigarrado']
# 'Que tiene muchos colores o elementos juntos'

Nota: Intentar acceder a una clave inexistente produce un KeyError.

Uso de get()

El método get() permite acceder a un valor sin riesgo de error si la clave no existe.

Elaboración propia. Clic para ampliar.

Se puede indicar un valor por defecto:

glosario.get('efímero')
# 'Que dura poco tiempo'

glosario.get('inexistente')
# None

glosario.get('inexistente', 'No disponible')
# 'No disponible'

Añadir o modificar elementos

Se puede asignar un valor a una clave para añadirla o modificarla:

glosario['audaz'] = 'Que se atreve con facilidad'
glosario['audaz'] = 'Que actúa con valor y decisión'
glosario
# {'efímero': 'Que dura poco tiempo',
#  'abigarrado': 'Que tiene muchos colores o elementos juntos',
#  'solapado': 'Que actúa con disimulo',
#  'audaz': 'Que actúa con valor y decisión'}

Creación desde vacío

Se puede construir un diccionario vacío e ir añadiendo elementos progresivamente:

vowels = 'aeiou'
posiciones = {}
for i, letra in enumerate(vowels):
    posiciones[letra] = i + 1

posiciones
# {'a': 1, 'e': 2, 'i': 3, 'o': 4, 'u': 5}

Pertenencia de una clave

El operador in permite comprobar la existencia de una clave:

'efímero' in glosario
# True

'colérico' in glosario
# False

'solapado' not in glosario
# False

Obtener todos los elementos

glosario.keys()
# dict_keys(['efímero', 'abigarrado', 'solapado', 'audaz'])

glosario.values()
# dict_values(['Que dura poco tiempo',
#              'Que tiene muchos colores o elementos juntos',
#              'Que actúa con disimulo',
#              'Que actúa con valor y decisión'])

glosario.items()
# dict_items([
#   ('efímero', 'Que dura poco tiempo'),
#   ('abigarrado', 'Que tiene muchos colores o elementos juntos'),
#   ('solapado', 'Que actúa con disimulo'),
#   ('audaz', 'Que actúa con valor y decisión')
# ])

Longitud de un diccionario

len(glosario)
# 4

Iterar sobre un diccionario

# Iterar sobre claves
for palabra in glosario.keys():
    print(palabra)

# Iterar sobre valores
for significado in glosario.values():
    print(significado)

# Iterar sobre clave-valor
for palabra, significado in glosario.items():
    print(f'{palabra}: {significado}')

Nota: En la iteración sobre clave-valor se utilizan f-strings para formatear las cadenas.

Combinar diccionarios

dic1 = {'a': 1, 'b': 2}
dic2 = {'b': 3, 'c': 4}

# Sin modificar los originales
{**dic1, **dic2}
# {'a': 1, 'b': 3, 'c': 4}

# A partir de Python 3.9
dic1 | dic2
# {'a': 1, 'b': 3, 'c': 4}

# Modificando dic1
dic1.update(dic2)
dic1
# {'a': 1, 'b': 3, 'c': 4}

Borrar elementos

glosario = {'efímero': 'Que dura poco tiempo', 'abigarrado': 'Que tiene muchos colores', 'solapado': 'Que actúa con disimulo'}

# Por clave
del(glosario['efímero'])

# Extracción con pop
glosario.pop('abigarrado')

# Borrado completo
glosario.clear()
# o reinicializando
glosario = {}

Nota: La diferencia entre clear() y reinicializar con {} afecta a la gestión interna de memoria y rendimiento.

You Should Know

Errores comunes en operaciones con diccionarios

Al trabajar con diccionarios, pueden producirse errores si no se tienen en cuenta ciertas condiciones. A continuación se muestran los más frecuentes.

1. Acceso a una clave inexistente

Intentar acceder a una clave que no existe provoca un KeyError:

glosario = {'python': 'Lenguaje de programación', 'java': 'Otro lenguaje'}

glosario['c++']
# KeyError: 'c++'

2. Uso de tipos no hashables como clave

Las claves de un diccionario deben ser inmutables. Intentar usar una lista o un diccionario como clave genera un TypeError:

mi_dic = {}
mi_dic[['a', 'b']] = 1
# TypeError: unhashable type: 'list'

3. Uso incorrecto de pop() con clave inexistente

Si se intenta extraer un elemento con pop() y la clave no existe, se obtiene un KeyError:

glosario.pop('ruby')
# KeyError: 'ruby'

Truco: Para evitar errores con pop(), se puede indicar un valor por defecto: glosario.pop('ruby', 'No existe').

4. Asignación con paréntesis mal usada

Intentar borrar un elemento usando paréntesis incorrectos genera un SyntaxError:

del(glosario['python'])
# Esto es correcto

del glosario('python')
# SyntaxError: cannot delete function call

Nota: Siempre se debe utilizar la sintaxis correcta para borrar claves: del diccionario['clave'].

A Step Ahead

Resumen de operaciones con diccionarios

Se presenta un resumen de las operaciones más habituales con diccionarios, así como algunas menos frecuentes. Para más información, se puede consultar la documentación oficial de Python sobre diccionarios.

Operación Descripción Ejemplo
Acceso por clave Obtiene el valor asociado a una clave existente. d['clave']
get() Obtiene el valor de una clave. Devuelve None o un valor por defecto si no existe. d.get('clave', 'No existe')
Asignación Añade un elemento nuevo o modifica uno existente. d['clave'] = valor
update() Actualiza un diccionario con otro, añadiendo o sobrescribiendo claves. d.update({'nueva': 10})
keys() Devuelve un iterable con todas las claves. d.keys()
values() Devuelve un iterable con todos los valores. d.values()
items() Devuelve un iterable de pares clave-valor como tuplas. d.items()
pop() Elimina y devuelve el valor de una clave. Se puede dar valor por defecto. d.pop('clave', None)
popitem() Elimina y devuelve el último par clave-valor agregado (Python 3.7+). d.popitem()
clear() Elimina todos los elementos del diccionario. d.clear()
copy() Devuelve una copia superficial del diccionario. copia = d.copy()
fromkeys() Crea un diccionario a partir de un iterable, asignando un mismo valor a todas las claves. dict.fromkeys(['a','b'], 0)
setdefault() Devuelve el valor de una clave si existe; si no, la añade con un valor por defecto. d.setdefault('clave', 0)
Comprobación de pertenencia Comprueba si una clave está presente en el diccionario. 'clave' in d
Iteración Permite recorrer claves, valores o pares clave-valor. for k, v in d.items(): ...
Combinación de diccionarios Une dos diccionarios. Con | (Python 3.9+) o **. d3 = d1 | d2

Muchas de estas operaciones devuelven vistas dinámicas del diccionario (como keys(), values(), items()), por lo que reflejan los cambios que se realicen posteriormente en el diccionario.

students = {
