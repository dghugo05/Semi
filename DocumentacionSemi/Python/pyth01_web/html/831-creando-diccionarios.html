8.3.1 Creando diccionarios

FPD - Free Text

Para crear un diccionario en Python se utilizan llaves {} rodeando asignaciones clave: valor separadas por comas. Cada clave debe ser única y los valores pueden ser de cualquier tipo de datos.

Representación conceptual de la creación de un diccionario agrupando pares clave: valor dentro de la estructura.

Elaboración propia. Clic para ampliar.

Veamos algunos ejemplos:

# Diccionario vacío
empty_dict = {}

# Diccionario con claves y valores de tipo string
spanish_words = {
    'altruista': 'Que busca el bien de los demás',
    'melómano': 'Amante de la música',
    'nómada': 'Que se desplaza de un lugar a otro'
}

# Diccionario con claves y valores de tipo entero
population_city = {
    2010: 1_200_000,
    2011: 1_225_500,
    2012: 1_248_900,
    2013: 1_275_300,
    2014: 1_300_800
}

En los ejemplos anteriores se puede observar:

  • Creación de un diccionario vacío.
  • Creación de un diccionario con claves y valores de tipo cadena.
  • Creación de un diccionario con claves y valores de tipo entero.
