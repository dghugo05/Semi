9. Modularidad

Situation

CC by fauxels

El equipo de sistemas de TechServe, después de comenzar su fase piloto de aprendizaje de Python, se enfrenta al siguiente desafío: los scripts antiguos son difíciles de mantener y apenas reutilizables. Marta, la administradora principal, decide que es momento de enseñar conceptos de programación más avanzados para que los técnicos puedan escribir código más organizado y robusto.

Durante la reunión, Marta explica que la modularidad permite dividir los programas en partes pequeñas y manejables, facilitando la comprensión y el mantenimiento. Además, introduce las funciones, que permiten agrupar instrucciones reutilizables y evitar repetir código.

El siguiente paso es trabajar con objetos y clases para modelar elementos del mundo real dentro de los programas, encapsulando datos y comportamientos de forma estructurada. Por último, Marta enfatiza la importancia de las excepciones, enseñando al equipo a anticipar errores y manejar situaciones inesperadas sin que los programas se bloqueen.

Con estos conocimientos, el equipo estará preparado para transformar los antiguos scripts en herramientas más eficientes y fiables, mejorando la productividad y reduciendo errores en las tareas críticas del día a día en TechServe.

FPD - Free Text

La modularidad es un principio de programación que consiste en dividir un programa en partes independientes o módulos, de manera que cada uno cumpla una función concreta. Esto permite escribir código más legible, reutilizable y fácil de mantener.

En Python, la modularidad se logra de forma natural mediante la creación de funciones, clases y archivos separados que se pueden importar cuando se necesiten. Por ejemplo, un módulo sencillo podría contener funciones matemáticas:

# archivo operaciones.py
def sumar(a, b):
    return a + b

def restar(a, b):
    return a - b

Este módulo se puede importar en otro archivo de Python:

import operaciones

resultado = operaciones.sumar(5, 3)
print(resultado)
# Salida: 8

Comparando con otros lenguajes:

  • En C o C++, la modularidad se consigue con archivos .h y .c/.cpp que luego se enlazan al compilar, lo que requiere un control más manual de dependencias.
  • En Java, se usan paquetes y clases para organizar módulos, pero siempre dentro de la estructura de clases y con compilación previa.
  • Python permite importar módulos de manera sencilla, incluso en tiempo de ejecución, y ofrece la posibilidad de reutilizar scripts completos sin necesidad de compilación.

Dentro de este capítulo, la modularidad se trabajará a través de los siguientes puntos:

  • Funciones: Agrupación de instrucciones que se pueden reutilizar, con parámetros y valores de retorno.
  • Objetos y clases: Organización de datos y comportamientos relacionados, siguiendo el paradigma de programación orientada a objetos.
  • Excepciones: Manejo de errores y situaciones inesperadas para evitar que el programa se detenga, mejorando la robustez del código.

Gracias a la modularidad, los programas escritos en Python pueden crecer de manera ordenada, facilitar la colaboración entre varios desarrolladores y ser más fáciles de depurar y mantener.

El siguiente ejemplo muestra cómo la modularidad permite organizar un programa en distintas partes bien definidas. En él se utilizan funciones para dividir las tareas, clases para representar objetos con sus propios datos y comportamientos, y excepciones para manejar errores de forma controlada. Todos estos conceptos se estudiarán en detalle en los apartados siguientes.

Ejemplo práctico de modularidad

En un proyecto real, es habitual dividir el código en varios archivos según su función. A continuación, se muestra un ejemplo en el que se crea una pequeña aplicación para gestionar operaciones bancarias.

Archivo operaciones.py

def depositar(saldo, cantidad):
    """Suma una cantidad al saldo."""
    return saldo + cantidad

def retirar(saldo, cantidad):
    """Resta una cantidad del saldo, si es posible."""
    if cantidad > saldo:
        raise ValueError("Fondos insuficientes")
    return saldo - cantidad

Archivo cuenta.py

from operaciones import depositar, retirar

class CuentaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def ingresar(self, cantidad):
        self.saldo = depositar(self.saldo, cantidad)

    def extraer(self, cantidad):
        self.saldo = retirar(self.saldo, cantidad)

    def mostrar_saldo(self):
        print(f"Saldo actual de {self.titular}: {self.saldo} €")

Archivo principal main.py

from cuenta import CuentaBancaria

def main():
    cuenta = CuentaBancaria("Marta", 500)

    try:
        cuenta.ingresar(200)
        cuenta.extraer(800)
        cuenta.mostrar_saldo()
    except ValueError as e:
        print("Error:", e)

if __name__ == "__main__":
    main()

En este ejemplo se observa cómo:

  • El archivo operaciones.py contiene funciones reutilizables.
  • El archivo cuenta.py define una clase que usa esas funciones.
  • El archivo main.py ejecuta la aplicación, gestionando posibles errores con try...except.

Este enfoque modular facilita la lectura, depuración y ampliación del código. Por ejemplo, se podrían añadir nuevos tipos de cuentas o registrar las operaciones en un archivo sin modificar el resto del programa.

En resumen, la modularidad permite dividir un programa en partes más pequeñas, reutilizables y fáciles de mantener. En los siguientes apartados se profundizará en las funciones como herramienta principal para estructurar el código, en la programación orientada a objetos como forma avanzada de organizar proyectos complejos, y en el manejo de excepciones para lograr programas más robustos y seguros.

La modularidad es una característica fundamental de la programación que consiste en dividir un programa en partes más pequeñas o módulos independientes. Cada módulo se encarga de una tarea específica y puede ser reutilizado en distintos programas.

En Python, la modularidad se consigue mediante el uso de funciones y módulos , lo que permite organizar el código de forma clara y mantenerlo fácilmente. Además, los programas se pueden ampliar sin necesidad de modificar el código ya existente.

Comparado con otros lenguajes, Python destaca por su sencillez y por ofrecer una estructura modular muy flexible , que facilita la creación de proyectos grandes y colaborativos.
