9.2 Objetos y clases

FPD - Free Text

Python es un lenguaje orientado a objetos. Todo en Python es un objeto, incluyendo números, cadenas, listas, funciones, e incluso clases. Comprender los conceptos de clase y objeto es fundamental para escribir programas organizados y reutilizables.

Elaboración propia. Clic para ampliar.

Una clase es un molde o plantilla que define atributos (propiedades) y métodos (funciones) que tendrán sus objetos.

# Definición de una clase sencilla
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad
    
    def saludar(self):
        print(f"Hola, mi nombre es {self.nombre} y tengo {self.edad} años.")

# Crear un objeto de la clase Persona
persona1 = Persona("Ana", 20)
persona1.saludar()
# Salida: Hola, mi nombre es Ana y tengo 20 años.

En este ejemplo, __init__ es un método especial llamado constructor, que se ejecuta automáticamente al crear un objeto. Los atributos nombre y edad se asignan al objeto mediante self, que hace referencia a la instancia actual.

Un objeto es una instancia de una clase. Cada objeto puede tener valores distintos en sus atributos, aunque comparta los mismos métodos.

persona2 = Persona("Luis", 25)
persona2.saludar()
# Salida: Hola, mi nombre es Luis y tengo 25 años.

Comparativa con otros lenguajes

En lenguajes como Java, las clases y objetos funcionan de manera similar, pero hay diferencias:

  • En Java, es obligatorio declarar el tipo de cada atributo.
  • Los constructores en Java tienen el mismo nombre que la clase y no usan self.
  • Python permite la creación de objetos dinámicamente, mientras que en Java se requiere tipado estático.
public class Persona {
    String nombre;
    int edad;

    public Persona(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    public void saludar() {
        System.out.println("Hola, mi nombre es " + nombre + " y tengo " + edad + " años.");
    }
}

Herencia

La herencia permite crear nuevas clases basadas en otras existentes, reutilizando atributos y métodos.

# Clase base
class Animal:
    def __init__(self, nombre):
        self.nombre = nombre
    
    def hablar(self):
        pass

# Clase derivada
class Perro(Animal):
    def hablar(self):
        print(f"{self.nombre} dice: ¡Guau!")

mi_perro = Perro("Firulais")
mi_perro.hablar()
# Salida: Firulais dice: ¡Guau!

Polimorfismo

El polimorfismo permite que distintas clases implementen métodos con el mismo nombre, pero con comportamientos específicos.

class Gato(Animal):
    def hablar(self):
        print(f"{self.nombre} dice: ¡Miau!")

animales = [Perro("Rex"), Gato("Misi")]

for a in animales:
    a.alimentar()  # Cada objeto responde según su clase

Resumen de conceptos clave

  • Clase: plantilla que define atributos y métodos.
  • Objeto: instancia concreta de una clase.
  • Atributos: variables asociadas a un objeto.
  • Métodos: funciones asociadas a un objeto.
  • Herencia: permite que una clase derive de otra.
  • Polimorfismo: permite usar métodos con el mismo nombre en distintas clases, con comportamientos distintos.

Al comprender y aplicar estos conceptos, los alumnos podrán diseñar programas más organizados y reutilizables en Python, aplicando conocimientos previos de programación orientada a objetos en otros lenguajes.
