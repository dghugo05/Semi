4.2 Enteros

FPD - Free Text

Los números enteros en Python (int) no contienen decimales, pero pueden ser positivos o negativos y expresarse en diferentes bases, como binaria, octal o hexadecimal.

Elaboración propia. Clic para ampliar.

Nota: No se puede comenzar un número entero con 0, y Python permite usar guiones bajos _ para mejorar la legibilidad de números grandes. Por ejemplo:

number1 = 42
number2 = -7
number3 = 1_000_000
print(number1, number2, number3)

Operaciones con enteros

Python permite realizar diversas operaciones con enteros:

a = 10
b = 3

# Suma
print(a + b)  # 13

# Resta
print(a - b)  # 7

# Multiplicación
print(a * b)  # 30

# División flotante
print(a / b)  # 3.3333333333333335

# División entera
print(a // b) # 3

# Módulo
print(a % b)  # 1

# Exponenciación
print(a ** b) # 1000

Consejo: Es recomendable dejar espacios alrededor de los operadores para mejorar la legibilidad. Hay que tener cuidado con operaciones que puedan generar errores, como la división por cero.

Asignación aumentada

La asignación aumentada combina un operador con la asignación para actualizar el valor de una variable de manera compacta. Por ejemplo:

stock_cars = 50
sold_cars = 12

# Asignación tradicional
stock_cars = stock_cars - sold_cars
print(stock_cars)  # 38

# Asignación aumentada
stock_cars = 50
sold_cars = 12
stock_cars -= sold_cars
print(stock_cars)  # 38

# Otros ejemplos
number = 10
number += 5   # 15
number *= 2   # 30
number //= 3  # 10
number **= 2  # 100

Módulo y exponenciación

El operador módulo % devuelve el resto de una división:

dividendo = 23
divisor = 5
cociente = dividendo // divisor
resto = dividendo % divisor
print(cociente)  # 4
print(resto)     # 3

La exponenciación se realiza con el operador **:

print(3 ** 4)    # 81
print(2 ** 0.5)  # 1.4142135623730951 (raíz cuadrada)

Valor absoluto

La función abs() devuelve el valor absoluto de un número:

print(abs(-7))      # 7
print(abs(3.14))     # 3.14
print(abs(-12345))   # 12345

Límite de un entero

En Python, los enteros pueden ser de tamaño arbitrario, limitados únicamente por la memoria disponible:

very_large = 10 ** 500
print(very_large)

Nota: En otros lenguajes, valores tan grandes podrían causar un integer overflow, pero Python los maneja correctamente.

Caso practico

Contexto: Se dispone de variables numéricas que representan cantidades de productos y operaciones de inventario en una tienda:

apples = 15
oranges = 7
total_stock = 120
sold_items = 32
bonus_multiplier = 3
extra_stock = 10
