6.4 Operadores de comparación

FPD - Free Text

Expresiones de comparación y operadores lógicos

Al trabajar con condicionales, es fundamental conocer los operadores de comparación que Python ofrece. Estos operadores permiten evaluar relaciones entre valores y siempre devuelven un resultado booleano (True o False).

Operador Significado
== Igualdad
!= Desigualdad
< Menor que
<= Menor o igual que
> Mayor que
>= Mayor o igual que 
# Ejemplos de comparación
>>> score = 15
>>> score == 15
True
>>> score != 10
True
>>> score < 20
True
>>> score <= 14
False
>>> score > 5
True
>>> score >= 18
False

Es posible combinar varias condiciones utilizando operadores lógicos como and, or y not:

# Uso de operadores lógicos
>>> x = 7
>>> x > 3 and x < 10  # True and True
True
>>> x > 10 or x < 5  # False or False
False
>>> not(x < 10)        # not True
False

Python permite comprobar si un valor se encuentra dentro de un rango de manera directa:

# Verificar si un valor está entre dos límites
>>> 5 <= score <= 20
True

Booleanos en condiciones

Cuando una variable booleana se utiliza en una condición, se puede simplificar la comparación:

# Forma explícita
>>> is_hot = False
>>> if is_hot == True:
...     print("Ponte gafas de sol")
... else:
...     print("No hace falta")
...
No hace falta

# Forma simplificada
>>> if not is_hot:
...     print("No hace falta")
... else:
...     print("Ponte gafas de sol")
...
No hace falta

Este estilo reproduce de manera natural la lógica del lenguaje humano:

  • Si hace calor, ponte gafas de sol.
  • Si no hace calor, no hace falta.

Valor nulo

En Python, None representa la ausencia de valor. Al incorporarlo en condiciones, se comporta como False:

# Comprobación de valor nulo
>>> data = None
>>> if data:
...     print("Valor presente")
... else:
...     print("Valor vacío")
...
Valor vacío

Para comprobar explícitamente si una variable es nula se recomienda usar el operador is:

# Comprobación con 'is'
>>> data = None
>>> if data is None:
...     print("Valor claramente nulo")
... else:
...     print("Valor contiene información")
...
Valor claramente nulo

# Comprobación inversa con 'is not'
>>> data = 42
>>> if data is not None:
...     print(f"{data=}")
...
data=42

Nota: None en Python equivale a nil, null o nothing en otros lenguajes.

Caso practico

Se dispone de varias variables que pueden contener valores enteros, booleanos o nulos. El objetivo es practicar la evaluación de condiciones usando operadores de comparación, booleanos y el valor especial None en Python.
