8.1.5 Veracidad múltiple

FPD - Free Text

Si bien se pueden usar sentencias condicionales para comprobar la veracidad de determinadas expresiones, Python ofrece dos funciones built-in que permiten evaluar condiciones múltiples: all() para comprobar si se cumplen todas las condiciones y any() para comprobar si se cumple alguna. Estas funciones trabajan sobre iterables, siendo el ejemplo más común una lista.

Supongamos un ejemplo en el que se quiere comprobar si una determinada palabra cumple las siguientes condiciones:

  • Su longitud total es mayor que 5.
  • Empieza por "c".
  • Contiene, al menos, una "e".

Versión clásica usando condicionales:

word = 'cereal'
if len(word) > 5 and word.startswith('c') and word.count('e') >= 1:
    print('Cool word!')
else:
    print('No thanks')
# Cool word!

Versión usando all() (todas las condiciones deben cumplirse):

word = 'cereal'
long_enough = len(word) > 5        # True
starts_correctly = word.startswith('c')  # True
contains_e = word.count('e') >= 1   # True

is_cool_word = all([long_enough, starts_correctly, contains_e])
if is_cool_word:
    print('Cool word!')
else:
    print('No thanks')
# Cool word!

Versión usando any() (al menos una condición debe cumplirse):

word = 'note'
long_enough = len(word) > 5        # False
starts_correctly = word.startswith('c')  # False
contains_e = word.count('e') >= 1   # True

is_fine_word = any([long_enough, starts_correctly, contains_e])
if is_fine_word:
    print('Fine word!')
else:
    print('No thanks')
# Fine word!

Nota: Estas funciones son muy útiles para simplificar expresiones condicionales complejas y hacer el código más legible.
