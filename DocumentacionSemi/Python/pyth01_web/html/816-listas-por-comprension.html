8.1.6 Listas por comprensión

FPD - Free Text

Las listas por comprensión constituyen una técnica que permite crear listas de forma más compacta, basándose en el concepto matemático de conjuntos definidos por comprensión.

Ejemplo de código: 

Ejemplo clásico

Supongamos que se desea convertir una cadena de texto con valores numéricos en una lista de enteros. En su versión clásica se realizaría de la siguiente manera:

values = '12,34,56,78,90'
int_values = []
for value in values.split(','):
    int_value = int(value)
    int_values.append(int_value)

int_values
# [12, 34, 56, 78, 90]

En la siguiente imagen se puede observar como se iría construyendo la lista en cada iteración.

Elaboración propia. Clic para ampliar.

Ejemplo con lista por comprensión

Utilizando una lista por comprensión, el código anterior puede simplificarse de esta forma:

values = '12,34,56,78,90'
int_values = [int(value) for value in values.split(',')]

int_values
# [12, 34, 56, 78, 90]

Condiciones en comprensiones

Es posible incluir condiciones en las listas por comprensión. Por ejemplo, si solo se desean los valores que comiencen por el dígito 5:

values = '12,34,56,78,90,51'
int_values = [int(v) for v in values.split(',') if v.startswith('5')]

int_values
# [56, 51]

Anidamiento en comprensiones

En listas por comprensión avanzadas, es posible utilizar bucles anidados para generar todas las combinaciones de una serie de valores:

values = '12,34,56'
svalues = values.split(',')
combinations = [f'{v1}x{v2}' for v1 in svalues for v2 in svalues]

combinations
# ['12x12', '12x34', '12x56', '34x12', '34x34', '34x56', '56x12', '56x34', '56x56']

Caso practico

Se desea generar una lista con los resultados de una función matemática, usando listas por comprensión para practicar su uso.

You Should Know

Consejo: Las listas por comprensión son muy potentes y útiles en muchas situaciones, pero conviene evitar expresiones demasiado complejas. En esos casos, una aproximación clásica suele ser más clara.
