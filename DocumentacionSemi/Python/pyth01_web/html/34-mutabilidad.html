3.4 Mutabilidad

FPD - Free Text

En Python, las variables son nombres que hacen referencia a objetos en memoria, no contenedores que almacenan los valores directamente. Cuando se asigna un valor a una variable, el nombre apunta a la zona de memoria donde se representa el objeto.

Por ejemplo, al asignar un valor a una variable:

>> x = 10

Si se asigna esta variable a otra:

>> y = x

Ambos nombres apuntan al mismo objeto en memoria. La función id() permite comprobar la dirección de memoria de un objeto:

>> id(x)
4445989712
>>> id(y)
4445989712

Importante: La mutabilidad se relaciona con la capacidad de un objeto de cambiar su valor sin cambiar su dirección de memoria.

Por ejemplo, los enteros son inmutables, ya que al modificar su valor se crea un nuevo objeto:

>> x = 10
>>> id(x)
4310690224
>>> x = 25
>>> id(x)
4310690288<br />

En cambio, las listas son mutables. Modificar uno de sus elementos no cambia la dirección de memoria de la variable:

>> fruits = ["apple", "banana", "cherry"]
>>> id(fruits)
140591274192576
>>> fruits[1] = "orange"
>>> id(fruits)
140591274192576

You Should Know

Que un objeto sea inmutable significa que su valor no se puede modificar in situ, pero siempre se puede asignarle un nuevo valor, haciendo que el nombre apunte a otra zona de memoria.

Para seguir la ejecución de manera visual, se recomienda usar Python Tutor, que permite ver paso a paso cómo se asignan y modifican los objetos en memoria.
