Recursos necesarios y recomendaciones

RECURSOS NECESARIOS:

  • Ordenador personal con sistema operativo Windows o GNU/Linux.
  • Java JDK25 o superior instalado en el ordenador.
  • IDE como NetBeans, VS Code o cualquier otro entorno para desarrollo en Java.
  • Los apuntes teóricos correspondientes a la unidad de trabajo DEINTH01.

RECOMENDACIONES:

Es conveniente que previamente hayas repasado todos los contenidos de la unidad (y los ejemplos que contienen) y hayas practicado con algunos ejercicios sencillos, de forma que tengas confianza con las clase y los contenedores.

Indicaciones de entrega

Una vez realizada la tarea, se creará una carpeta y se guardarán en ella los archivos Java con el código fuente del contador (contador.java)

Se comprimirá la carpeta en formato zip.

El envío se realizará a través de la plataforma. El archivo se nombrará siguiendo las siguientes pautas (sustituyendo cada uno el primer apellido y el nombre por el suyo):

Apellido1_Apellido2_Nombre_DI_TOXX_UTXX

Es muy importante que incluyas comentarios describiendo variables, constantes, funciones, algoritmos y cualquier decisión de diseño que hayas tomado en tu código.
