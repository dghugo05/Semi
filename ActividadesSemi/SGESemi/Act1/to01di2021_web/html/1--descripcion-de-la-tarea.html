TO01_DI_2021

1.- Descripción de la tarea

Caso práctico

Marta está empezando a familiarizarse con los sistema ERP-CRM y como parte de su aprendizaje va a instalar Odoo en distintos sistemas operativos, con distintas configuraciones y tiene que verificar la correcta gestión de la base de datos.

FPD - Free Text

¿Qué te pedimos que hagas?

Objetivo: Aprender a instalar y configurar Odoo en diferentes entornos (Windows, Linux y Docker), documentando el proceso con pantallazos y explicaciones breves, incluyendo el usuario de Moodle para identificar la autoría.

Actividades a realizar:

Actividad 1: Instalación en Windows
Realiza la instalación de Odoo en Windows (10 o 11 recomendados): descarga Odoo y dependencias, instala PostgreSQL, configura Odoo y ejecuta el servidor. Incluye pantallazos de cada paso con tu usuario de Moodle visible y una breve explicación.

Actividad 2: Instalación en Linux
Instala Odoo en una distribución Linux (Ubuntu recomendado). Configura PostgreSQL y accede a la interfaz web de Odoo. Documenta el proceso con pantallazos claros y explicaciones, incluyendo tu usuario de Moodle.

Actividad 3: Instalación en Docker
Crea un archivo docker-compose.yml que levante un stack completo con Odoo + PostgreSQL. Configura volúmenes locales para persistencia de datos y asegúrate de que los contenedores se comuniquen correctamente. Incluye pantallazos de la ejecución y acceso a Odoo desde el navegador.

Actividad 4: Configuración de puerto personalizado
Configura Odoo para usar un puerto distinto de 8069. Documenta cómo acceder a la aplicación desde el navegador con el nuevo puerto configurado. Incluye pantallazos.

Actividad 5: Verificación final de configuraciones
Verifica el correcto funcionamiento en cada sistema (Windows, Linux y Docker) mostrando pantallazos de: servicio PostgreSQL activo, configuración de puertos y acceso a la interfaz web de Odoo. Incluye usuario Moodle en los pantallazos.

Actividad 6: Documentación e incidencias
Elabora un documento ordenado con todos los pantallazos y explicaciones. Registra las incidencias producidas durante la instalación y cómo las resolviste. El usuario de Moodle debe aparecer en cada pantallazo.

Actividad 7 ( Avanzada): Extensión con pgAdmin
Añade un contenedor adicional para pgAdmin (u otra herramienta de gestión de bases de datos). Documenta la estructura de carpetas de Docker, cómo se comunican los contenedores y prueba la persistencia de datos eliminando y reiniciando los contenedores sin perder información.
